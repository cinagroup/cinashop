# 客服商品上下文图片迁移（2026-11-16）

本批让客服已购、浏览、推荐商品和详情，以及游客商品详情，对已登记的附件按商品所有者、供应商状态、附件模块、对象路径和图片 MIME 统一授权，再返回短期签名图片地址。商品与附件权限在同一 SQL 快照读取，防止不同时间的所有者与附件记录拼接出错误授权。

基线 `9d1d455e844e01efc389646bb8ed43963134f7f7`；源码 20 文件（12 个既有文件、8 个新增文件），保护其余 9358 个既有文件；另交付本说明与机器报告。整个 PHP → TypeScript 迁移仍在进行。

## 行为与兼容

- 范围为 `/kefuapi/product/cart/:uid`、`visit/:uid`、`hot/:uid`、`info/:id` 和 `/kefuapi/tourist/product/:id`。复用既有公开商品附件策略，批量授权；不读取 R2 来生成 JSON，也不写入业务资源。
- 平台商品使用平台附件；门店商品要求合法正整数门店 ID，使用平台附件；登记附件的供应商授权要求供应商启用且未删除，并只允许自身或平台附件；安全的历史图片引用保留既有兼容行为。非法所有者、异属用户或供应商的登记附件、未登记附件及错误元数据不能获得附件签名。
- 主图遵守 256 字符字段限制；轮播图按整个 JSON 字段 5000 字符限制处理，保留所有字符串的位置、顺序、重复项和空项，只过滤原本的非字符串。安全的历史 HTTPS/站内引用不被套用主图长度限制。整批超过 10000 引用时在附件授权 SQL 前拒绝；此前可能已执行商品或会话查询。
- 登记附件引用移除旧签名参数并重新签名；实体只解码一次，解码后的控制字符、DEL 和反斜杠也拒绝。内部所有者字段不会出现在响应。
- 自有事务使用有界 5 秒 `REPEATABLE READ, READ ONLY` 快照，提交后才执行 HMAC；调用方已有事务保持隔离级别和提交/回滚所有权。初始客服会话检查仍在快照前，历史查询保留当前会话与客户检查；显式商品名搜索仍按既有规则扩大到公开商品库。原有可见性、排序、重复浏览记录、金额、库存及描述行为保留。
- 实际移动浏览发现关闭状态的快捷回复面板遮挡商品卡片，已在原有 720px 媒体规则内修复，并重验真实卡片点击和详情。
