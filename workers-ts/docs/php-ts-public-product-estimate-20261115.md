# 普通商品单件预估迁移

本批为 Uni 普通商品详情增加独立的“单件预估到手”面板。选定真实规格后，展示数量1的商品原价、会员、促销、首单和最优单张优惠券减免及预计应付；多件选择明确提示仍仅预估1件。已领取券和需要领取的发行券分别显示，不生成虚构的已领券ID，也不把预估写入购买或领取日志。运费、积分和支付不包含在内，结算必须重新确认。

入口为 GET `/api/product/detail/activity/:id?view=uni_product_estimate_v1&unique=<真实SKU>`；原无view入口保留既有响应。新入口严格拒绝重复/未知参数及客户提供的金额、数量、UID、券ID和报价凭证，返回 private,no-store/no-cache/no-referrer。有令牌时必须真实鉴权，失效令牌不能退为游客；只读鉴权不清除令牌桶。真实买家在快照前、中、后复查，避免账号失效后释放私有结果。

全部事实在一次 REPEATABLE READ、READ ONLY SQL事务中读取，并设置语句/锁/空闲超时。默认选择最低原始价、再按实际SKU ID排序；明确规格不替换，最低价规格无库存也不偷偷改选。合法零价保留，坏金额和不完整数据显式失败。会员、促销、首单及券金额均复用既有计算和严格DTO守恒校验；首单合格但优惠为零时仍保留排他规则。

券选择完整比较本人的有效已领券、可领取普通发行券和真正符合会员权益的发行券，按实际节省金额选最大；同额优先已领，再按实际ID。两个来源分别1000+1探测，超限报错，不把3/50条目录当全局最优。领取资格提取为共享纯判断，真实领取仍保留原事务锁、领取历史、库存扣减、落库与幂等。券按发行时已领条款计算，未领发行券的ownedId为null。该稳定同额顺序和容量上限是明确TS边界，不宣称独立证明PHP的同额排序。

金额示例保留原规则：19.99元、85.99折扣券优惠3.00、应付16.99；同折扣首单仍优惠2.99。促销90折在19.99元上优惠1.99，剩18.00；再用85.99券优惠2.70、应付15.30。固定PHP源码和前批独立表达式oracle用于核对，没有启动PHP完整框架预估服务。预估读取新鲜SQL配置，现有结算仍可能受旧KV配置缓存影响；本批没有统一修改结算缓存来源。
