# Out 会员专属商品与购买资格（2026-11-11）

固定 PHP 来源为 `8ed2a5b139f9170dd11b0dff91803f2fd59e40a5`。Out 商品保存服务接受 `is_vip_product`；旧普通购物车在选购会员专属商品时调用 `checkUserIsSvip`，该检查要求会员功能开启且付费会员未过期或为永久会员。

本批支持平台实物商品会员专属开关的创建、更新、详情与幂等重放；省略保留原状态，显式关闭与历史忽略零值的回执区分。商品行与回执在同一事务，写入后和延迟约束后校验标志，既有商品行位置证明防止后续改写。会员价开关 `is_vip` 与会员专属开关独立。

普通购物车新增、修改数量和重选规格在写入前检查当前会员资格；事务末尾通过不等待的商品与会员行锁、既有计价来源能力锁和数据库墙上时钟再次核验。会员失效时现有普通购物车标记无效，但仍可删除。普通及其他非预售订单的报价检查专属资格、功能开关和用户状态；库存写入重新绑定商品标志，并使用既有会员快照和配置锁在最后等待后核验期限。报价摘要只对专属商品增加字段，普通商品的历史摘要保持原样；专属状态改变须重新确认。预售订单保留独立成熟资格规则。

旧版仅对已登录买家检查专属资格；本批保留已有的经授权代客或收银游客（UID 0）例外，普通匿名下单仍由既有来源校验拒绝。已登录的代客买家仍需满足会员资格。

验收使用隔离 PG16、合成用户和 Out 身份；受限 App LOGIN 使用现有权限计划及计价锁能力，不扩张生产授权。无数据库迁移、原生测试准入或 CI 工作流变更，未调用真实支付或外部提供商。
