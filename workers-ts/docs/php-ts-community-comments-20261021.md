# H5 社区完整评论与回复迁移

本轮基于 `c22747d155d18913b00ad42072c3752acad61a18`，共享完整评论组件与按帖子隔离的状态，覆盖主社区、作者工作区、话题／搜索详情及两个视频壳的当前视频。接通顶层与子回复独立分页、失败原页重试、精确回复根／子评论、显式点赞／取消、本人删除及根级联、审核反馈和评论／新增开关。公开总评论数、根列表数和当前用户可见回复数分别使用服务端合同，不能用已加载行数替代；根列表和子列表并行读取时，总数只接受最新发起的有效读取／写入结果，防止迟到旧页覆盖新计数。

后端抽取无副作用的帖子访问判定，不通过会增加浏览数的 detail() 充当只读守卫。读取以帖子生命周期锁保护快照，按既有 TS 的公共帖子／同类型本人预览范围过滤，再对根／子回复分页；点赞及嵌套保存锁后重验实际根和父帖。新增响应字段为可加兼容元数据，原 id 及接口路径保持；reply_id 拒绝含糊、负数及超界值。评论作者与回复目标分别按真实类型和编号投影，平台 UID0 使用站点名称／图片，目标不再错误复用当前评论的作者类型。

保留已审核本人隐藏评论的展示与删除，其他账号隐藏评论及待审评论不可读，隐藏根／子评论不能点赞或新增回复；不复制 PHP 登录 API 向旁观者暴露隐藏行的行为。既有 TS 持久化公开计数继续排除单行隐藏／未审核／删除状态，不改成按根可见性重新定义所有后代的计数。本轮没有生产 SQL、schema、迁移或权限变化，也没有增设举报功能。

前端操作绑定 postId、uid、token、sessionVersion、页面代次和可见性；换帖、换号、隐藏、卸载及组件销毁隔离迟到结果。未知写入标记仅存在同一个 auth store 的内存中，可跨评论 composable 销毁／重建及详情关闭重开；不保存评论内容／草稿，不声明整页重载或新会话持久化。网络、5xx、无效成功体清空旧视图并要求主动刷新，禁止自动重放；旧账号回执不能清除新账号的进行中标记。正常保存／删除后重新读取第一页，处理偏移分页变化。删除在评论行内保留／确认，绑定目标和有效期，取消不写入。

两个父页面保持共享组件挂载，以 postId=0 清理关闭状态，避免反复挂载向页面根重复注册 DCloud 生命周期。已核对锁定的 H5／MP injectHook 转发实现；实际 Vue effect scope 用例验证销毁、迟到回执和新 composable 的核对标记，浏览器另测关闭重开及跨页面／账号隔离。分页处理采用服务实际 int32 上限2147483647，包含超过1000页和上限验证，没有一千页静默截断。

评论定向657项独立用例通过（60项新增，最终零跳过）：Worker及运行器570、原生PG16的28项、H5运行时58项、实际浏览器1项。新增分布为绑定3、运行器8、原生28、H5运行时20、浏览器1；58项运行时已核对包含在最终完整工具链1404项内，窄跑与重复候选不另计。原有完整原生社区场景和真实并发锁等待仍执行。Worker两个完整类型项目及独立根浏览器配置的显式类型检查通过；UniApp完整合同包括类型检查、1404项工具链、admzip6、express7、jest4、D3门禁10与实时审计、H5／MP／App三端干净重建、产物4、automator5、运行时语言13及公共安全8。

后台浏览器25阶段完成68次实际业务请求（59次GET、9次写入）：根／子页各一次真实二页读取后503并原页重试、精确根／子回复、显式点赞与取消、行内删除保留、本人隐藏子／根删除及精确级联、待审反馈、已提交503后关闭重开不重放及主动核实、换帖换号、工作区／搜索／两个视频入口。逐次核对14表／14序列；普通读取零变化，实际detail读取仅允许目标play_num+1及必要的去重浏览关系／插入序列，不伪称所有GET零写。独立夹具控制仅两次修改指定审核配置并通过真实服务使对应KV失效，有单独配置收据，不计入9次业务写入。所有受保护旁观评论、第三方调用0、唯一未知提交仅一条均核实。最终库确有评论和关系变化，不声明恢复初态。
