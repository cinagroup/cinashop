# 买家按商品选择退款件数（2026-10-19）

购买两件时，PC和UniApp买家现在可申请退其中一件。PC数量控件显式14px字号，避免继承复选组零字号；Browser直接检查真实计算字号。每行区分购买数量和本次读取的剩余数量，默认取新读取的剩余数；无效输入保持可编辑并阻止提交。页面加减按钮、重新读取、未选中商品、迟到对象、会话/路由变化、上传中、提交中和结果未知均沿用上下文约束，异步提交保存独立冻结的行与数量。

实际HTTP正文为`cart_ids:[{cart_id:受保护商品行ID,cart_num:申请件数}]`。不发送内部cartSelections或privileged selectorNamespace，也不同时发送旧cartIds。成熟API继续支持旧cartIds的隐式剩余数量合同；资格、精确金额、并发锁和预留量仍由服务端决定，界面不自行乘算退款金额。本例一件的实际权威金额为12.80，取消释放一件后可重新申请两件25.60。
