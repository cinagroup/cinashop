# Out 商品标签与用户标签配置

本批接通平台实物商品 Out 保存入口的 `store_label_id` 和 `label_id`，并纳入既有品牌、保障和幂等事务。固定 PHP `8ed2a5b139f9170dd11b0dff91803f2fd59e40a5` 的控制器接受两类数组，创建监听器分别派发 type=3/4 关系，详情按存储编号读取 `id/label_name`。来源文件、行号及 Git blob/SHA256 见同名审计 JSON，旧 PHP 原文只保留在本地。

用户已明确选择与现有新商品编辑器一致的用户标签双写：显式 `label_id` 同时更新主表 CSV 和 type=4 关系。固定 PHP 保存服务对用户标签执行 `array_column`，Think ORM 又省略非 JSON 列的数组，导致旧主表未写、关系却被改写。本批修正这一 Out 行为；已有 Admin 旧兼容适配器保持其原合同。历史不在读请求或省略字段的保存中自动修复。

| 输入 | 合同 |
| --- | --- |
| 省略字段或内部调用传入 `undefined` | 保留该字段及关系，不读取其目录，保持旧归一化摘要形状。 |
| `store_label_id` | 最多100个规范正整数或十进制字符串编号。 |
| `label_id` | 同样最多100个编号，兼容旧详情的 `{id,label_name}` 回显；名称、归属、状态等回显不作为目录权限。CSV 还须满足当前 TS 主表64字符容量（后续详情批次修正原255判断）。 |
| 显式空数组 | 清除该字段和对应关系，以新意图绑定幂等键。升级前被忽略的空数组请求不能借旧键执行清除。 |

两类编号的重复、空值、标量、非规范数字和 int32 越界均拒绝。商品标签须属于平台、启用且显示，并位于 type=0、relation_id=0、owner_id=0、group=2、is_show=1 的商品标签组。用户标签须属于平台且启用；其分类仅作组织用途，沿用现有客户标签消费者的准入。所选实际标签行与商品标签组按数字编号顺序 SHARE NOWAIT 锁定，使用现有 App 权限，无新 schema、迁移或权限计划。

幂等摘要只绑定实际编号意图，回显名称变化不改变同一意图。原回执优先于当前目录准入，已提交请求可在目录后来隐藏或停用后重放；不同标签字段和编号不可复用同一键。四类元数据的标量、关系和回执同事务提交。协调器根据字段存在性确定关系拥有范围，其余关系的值及 xmin、被省略的元数据标量均保留。每个作者及最终回执后核对结果，后写用户标签或成功回执触发器破坏品牌、保障、商品标签、目录、分组或其它历史关系时整笔回滚。

详情沿用一个 REPEATABLE READ、READ ONLY 事务。在现有平铺 TS DTO 中，两类标签返回 `id/label_name` 数组；`store_label_selection` 和 `label_selection` 返回存储 CSV、编号、关系编号、一致性、当前可选性和截断标记。历史隐藏/停用标签可显示其原有平台名称；跨归属名称不输出，缺失或坏历史通过伴随状态报告。既有 Out 上下架形成的关系状态0/1均可构成一致存储。读取保持只读。

Out 保存配置不会直接修改顾客的 `user_label_relation` 或独立的旧商品标签辅助关系。商品公开标签继续由现有持久化 CSV、图片所有权与签名规则投影。验收包含真实下单后的四类组合保存、SKU/销量/订单保留、实际顾客端标签读取、同键并发创建、三个目录的锁竞争、各类触发器干扰、真实受限 LOGIN 和并发快照回读。HTTP Out 身份为合成账号，SQL 会话及数据库为真实独立 PG16；App 权限验收是现有计划在测试库上的投影，不作为完整生产角色安装证明。

新增39项与原有58项完整原生文件分别沿用原600秒子预算。原文件保持字节一致，验证器只增加一个明确文件名；分片收录核对和实际执行结果分别记录，不以收录证明全量执行通过。完整结果见同名机器审计及本轮完成记录。

新增验证入口改变了验证器完整哈希，因此历史来源读取器前增加一个仅覆盖该文件的精确后继：校验完整当前字节数、SHA256、Git blob 及唯一行位置，再仅逆转这一入口行至固定 `af2096c3` 原文件。旧来源证明、断言、运行器实际执行和时限均保持原样；未审阅改动、旧完整文件及重复入口均拒绝。

后续详情批次已接通旧版 Out 的 `tempList/cateList/productInfo` 完整外层，并核对目标用户标签列为64字符，见 [Out 商品详情完整外层](php-ts-out-product-detail-20261110.md)。本文件原批次的机器审计保留为历史记录。整体迁移仍未完成：旧 `OrderJob::setUserLabel` 购买商品标签作者链还需继续核对接通，当前 TS 付款后置仅有促销标签授予。远端固定旧 PHP 检出仍失败。本批未部署、未上传旧 PHP、未调用实际提供方。
