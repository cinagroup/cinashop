# H5 社区好友、关注与粉丝迁移

本轮基于 `10506fcb3a3ae39ca1aab3dcce5c95c608b3e18f`，补齐好友／关注／粉丝／推荐四个列表。旧 PHP `discoverFollow?type=0/1/2` 分别进入关注／好友／粉丝，保留数字合同；无效、重复或含糊参数拒绝，不透传私有查询。失败分页保留先前结果并重试原页，列表按实际服务上限一百万页处理，不能在一千页静默截断。

列表、分页和关注写入绑定账号、token、sessionVersion、页面代次及可见性；切换标签、换号、隐藏和卸载隔离迟到响应。UID0 的平台作者使用可空写锁，不与“没有写入”混淆。取消关注使用记录内保留／确认，确认绑定目标、所有者、代次和有效期；重复点击只写一次。网络、5xx或无效成功体按未知结果处理，清空旧列表，用户主动刷新成功后才解除，不自动重发。正常取消关注后重新读第一页，防止偏移分页跳过行。

后端按 `(type=0,relation_id=0)` 或 `(type=2,relation_id=真实UID)` 投影作者，过滤无效或已停用账号后再分页。同号虚拟、门店及其他类型档案不参与投影或计数更新。保留既有 TS 的有效账号可见规则与缺档案时的账号资料回退；读取不创建档案，档案 status=0 可在已有关系中显示，但不能进入推荐。好友按 PHP 社区档案编号降序，无档案账号置后按关系排序；推荐资格取最新有效同类型档案，避免旧行或异型行提供内容／粉丝资格。旧完整原生社交场景仍实际执行，补充类型碰撞、分页和资料回退检查。

完整重建发现两个真实编译缺陷：脚本代理 `workspace.vue` 缺少小程序 WXML，嵌套视频 `app.vue` 被锁定 DCloud 编译器误当根 App 而跳过组件注册。前者在编译前把固定两语句代理展开为同目录完整原始 SFC，保留页面根生命周期与相对导入；HMR 同时清除两文件模块缓存。后者仅对固定微信视频子页复用官方 main/script/template 描述符、组件缓存与动态导入流程，兼容外置块两种加载顺序；真正 App 分类及既有路由保持。产物检查沿真实 WXML 标签、usingComponents 和 createComponent 资源验证，保留原三项检查并增加一项，拒绝仅凭构建退出码宣布成功。其他小程序平台显式旁路，未作真机覆盖声明。
