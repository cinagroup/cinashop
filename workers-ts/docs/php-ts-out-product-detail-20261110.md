# Out 商品详情完整外层

`GET /outapi/product/:id` 现在同时提供既有平铺 TS DTO 和固定 PHP 的 `tempList`、`cateList`、`productInfo` 外层，保留三个驼峰键名。详情包括平台运费模板、可见分类树、存储字段的旧版转换、真实 SKU 编辑值、赠券、系统表单、推荐商品和品牌／保障／两类标签选集。固定 PHP 提交为 `8ed2a5b139f9170dd11b0dff91803f2fd59e40a5`；13 个完整来源文件的字节数、Git blob、SHA256 和行号见同名审计 JSON。本次只读取本地固定原文并核对对象，没有执行或上传旧 PHP。

用户明确选择虚拟库存与现有 TS 后台一致：普通详情只返回 `virtual_available`、`virtual_total`，保留空 `virtual_list` 供旧表单识别。查询不读取卡号、卡密。凭据继续通过已有 `/adminapi/product/virtual/:id/export-ticket` 和 `/adminapi/product/virtual/:id/export` 的受控导出读取。真实独立受限 LOGIN 的验收只获得 `product_id/attr_unique/uid` 三列读取权限，确认卡号、卡密列 SELECT 被 PostgreSQL 拒绝，真实 Hono 详情仍返回正确库存；另一商品的库存不计入，业务行及凭据保持不变。此验收是测试库上的权限投影，不是完整生产角色安装证明。

所有数据库展开读取位于一个 REPEATABLE READ、READ ONLY 事务。先检查商品是未删除的平台商品，再查询目录，避免跨归属或删除商品触达展开项。原文／行数在物化前预检：主体及目录的读取预检预算 1 MiB、完整集合最多10000项、单个编辑表单768 KiB、最终响应2 MiB；过大数据或重复站点配置明确拒绝，不截断目录后返回成功。查询使用本地超时；权限、锁竞争、超时及未就绪 schema 均报告不可用。既有路由与权限计划未改。

详情以实际规格行及 SKU 身份为准，不执行旧 PHP 在 GET 内补写规格结果的行为。缺失、歧义或不完整规格通过 `sku_repair_required` 报告，退役 SKU 在 `editor.retired_attrs` 单列，保持库存和历史身份。金额、佣金开关、活动名称、PHP JSON 空值／零字符串、上海时区时间、验证区间和原始 `disk_info` 按已核对的来源转换。模板范围仍为平台目录，历史停用模板／赠券可显示，不代表它们获准用于新写入。

编辑值与预览分开：持久化附件引用留在表单，图片按平台归属筛选，预览在事务后签名。描述编辑原文保留规范化引用，预览另做 HTML 清理及附件校验。视频保留原有持久化值，包括目前无法播放的历史 HTTP 链接；`editor.video_selection` 报告可用性，`video_preview` 只使用通过现有视频规则的引用。普通详情设为 `private, no-store`，不执行提供方 HTTP。

本批另修正上一批 Out 用户标签 CSV 的长度预检：目标 TS 模型及真实 PostgreSQL 列均为 `varchar(64)`，原255判断不符合目标 schema。现在直接从模型读取容量，并用真实 SQL 验证64字符成功、65字符提前拒绝且所有标量、关系和回执不变。上一批机器审计作为历史记录保留，本批审计明确记载更正。

验证保留原39项标签作者、原58项下单／Out 并发文件、历史来源证明与预算。新增纯投影检查，以及完整外层、媒体、边界、目录容量、并发快照、归属优先和卡密列拒绝的真实 PG16 检查。收录核对与实际执行分别记录，收录完整不代表全量分片已通过；具体结果见同名机器审计。

整体迁移仍在继续。读取这些历史字段不开放尚未迁移的活动、赠券、表单、预售等保存作者；购买商品后的用户标签作者链仍待接通。远端 Worker 全量 CI 仍受固定旧 PHP 提交缺失影响，本地定向通过不替代全量 CI。本批未部署、未上传旧 PHP、未调用实际提供方。
