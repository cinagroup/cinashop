## 原始证据与保留规则

`home_goods_list.vue:298` 和 `home_new_list.vue:186` 的完整默认字段均保留，包括原 `goodsList.max=20` 元数据。普通新选择的作者容量为当前消费者可验证的 100 个编号；该容量是本次作者策略，不声称是 PHP 原选择上限。导入项不会自动截断、合并默认值、补编号或把旧资料当成当前选择。PHP 普通商品默认值没有 `goodsList.ids`，这是作者中间状态，只有明确选择商品才添加身份。

## 真实目录与权限

新只读 GET 为 `/dise/author-options/list-products`、`list-brands`、`list-labels`、`list-article-categories`，同时注册 `/adminapi` 与 `/api/admin` 两个前缀。商品分类复用现有类型化 `tab-targets`。仅增加既有 `DISE_AUTHOR_SELECTION_PERMISSION` 的四个精确 GET/HEAD 入口；没有新增可分配权限，没有借用商品、品牌、标签、附件或 FAB 管理权限。

目录拒绝未知、重复、非规范分页、父级和控制字符；搜索按 100 个 Unicode 字符。响应验证分页、总数、重复编号、类型、名称及身份一致性。商品只提供当前可选择公开目标，品牌遵循可见平台祖先和三层边界并下钻到叶子，标签遵循平台可见条件，文章分类遵循实际公开标志。文章编号 0 是明确选择的热门聚合能力，空导入值不会自动变为 0。

公开预览使用匿名 GET，省略 Admin bearer 和 cookies，仅调用 `/api/products` 与 `/api/article/list/:cid`，不会调用详情、浏览、点赞、SKU 或购物车写接口。预览按钮禁用。商品名称、图片、边框、标签和价格来自当前公开 DTO，保存不写回签名图片或目录快照。原始旧快照仍是装修 JSON 的普通资料；它们不是公开媒体权限来源，继续遵守现有 editorial media policy。
