# H5 社区图集与视频封面

补齐 PHP 发布页已有的照片选择（最多 9 张）、移除照片、首图封面和视频封面上传。H5 图集与视频互斥，视频封面单独保存；原有文字发布和无封面视频接口仍兼容。照片从相册或相机选择，复用 `/api/upload/image`，每张最多 10 MiB。具体来源为 `cinashop-php/view/uniapp/pages/discover/discoverCreate/index.vue` 的图集模板、`uploadpic`、`uploadPoster` 和 `DelPic`；图片格式及大小沿用已迁移的附件服务。

数据库保存固定 `/api/assets/:id` 引用，预览和详情使用签名地址。用户发布/编辑含私有图片时，在事务内重新锁定账号和按 ID 排序锁定附件，校验归属、用户附件域、图片文件类型和固定引用。其他账号、客服/其他附件域、视频附件、签名预览地址及不存在的附件不能被当成自己的图片保存。读取先沿用社区可见性检查，再签发图片地址；历史脏记录的私有引用不会获得新的访问签名。待审核内容仍只允许作者从社区接口预览。

既有远程图片 URL 合同保留，只有私有附件引用需要上述校验。API 原有最多 20 个图集元素的兼容上限保持，新的 H5 选择器遵循 PHP 页面的 9 张限制。管理员图片作者逻辑未调整。`image_reference` 与 `slider_image_references` 返回保存的固定引用；`image`、`sliderImage` 和 `slider_image` 返回可展示来源。

一批照片串行上传，全部成功后才加入草稿；部分失败时不偷偷发布缩减的图集。用户可重新选择或明确移除全部照片。更换视频封面失败会保留旧预览并拦住发布，直到重新上传或明确移除封面。重复操作、切换账号、页面隐藏及卸载均有保护，迟到回执不会污染新草稿。移除草稿中的照片不会删除存储对象，也不新增垃圾回收政策。

详情支持完整图集及原生图片预览，视频使用所选封面。加载失败时用户可以重新读取签名；发布回执未知时继续沿用既有的禁止自动重试保护。`/api/get_script` 的已恢复行为保持。

## 验证边界

单元、H5 运行时及真实 PG16 并发测试涵盖归属更改、账号停用、事务回滚、审核可见性、错误附件域、失效私有引用、远程历史图片、图集顺序、首图替换、部分上传失败、封面失败、重复操作和生命周期隔离。运行命令与最终证据见本轮审计记录。

测试账号、JWT、PostgreSQL 数据库和图片均为本地合成数据，R2 使用内存字节存储。三份 PNG 是自行生成的 160×90 色块边框，不包含个人图片。本轮不代表生产 R2、真实设备摄像头、小程序或大图片负载验收；整体迁移仍未完成。

最终验收：479 项单元、27 项 H5、15 项原生 PG16 和 1 项浏览器测试通过，扣除 10 项重复的图片/视频原生重验后为 512 项独立用例，其中新增 20 项。两套完整 Worker 类型项目及 H5 类型检查/构建通过。后台浏览器在 390 像素 H5 页面内完成九阶段流程，32 次实际应用请求（其中 7 次 POST：5 次上传、2 次发布），3 份照片、1 份视频和 1 份独立封面均核对落库。页面不空白、无框架错误遮罩，无应用错误，存在一条既有 vue-router 废弃导入警告。原生预览另有截图证明。

首次浏览器验收因全页截图后的滚动位置变化导致误点测试控制按钮而中止，不计为通过；最终整轮重跑成功。全部 3 座本任务自有 PG16 实例确认停止，数据目录与日志保留。额外验收确认请求为 0，全局权限设置未修改。完整命令、哈希、失败候选和边界见[验收记录](../audit/php-ts-community-image-20261020.json)。
