# Out 商品列表筛选

固定 PHP `8ed2a5b139f9170dd11b0dff91803f2fd59e40a5` 的 `Product::productList` 调用管理商品搜索，而不是访客商城商品列表。Out 商品列表现在使用独立、只读的 REPEATABLE READ 快照，商品页和总数应用相同筛选。默认显示符合旧上架状态条件的普通及会员专享商品；`is_vip_product`、`is_presale_product`、`is_live`、`is_new`、`store_label_id`、`cate_id`、`store_name` 和 `type` 参与数据库筛选。旧代码的 `is_new` 使用类型3关系的 ID 4；标签也使用类型3关系，不能用商品列上的标签 CSV 替代。直播筛选排除未删除且审核状态不为3的直播商品。关键词覆盖商品字段、商品 ID 和 SKU 精确条码，不再把 Out 查询写入访客搜索历史。分类根节点按旧 path/关系选后代，非根节点选自己和直接子级。沿用既有 `brand_id` 扩展。

Out 接口仍要求既有令牌、账户及接口权限。按照旧接口的范围，列表不再套用商城的匿名会员商品隐藏和公开目录归属条件；原有商城读取规则没有改变。筛选参数使用有限整数和有界 ID 集，拒绝无效输入而不静默扩大查询。商品页面大小不超过100，列表输出继续使用既有 TS 卡片投影和图片策略。

本批是列表筛选迁移，不声称旧 PHP `searchList` 的完整商品字段、价格转换、规格／描述关系和分类名称投影已经对齐；这些仍需单独核对。本批不部署、不上传旧 PHP、不调用实际外部提供方。具体本地测试和远端 CI 状态以本批验收记录及推送后实际结果为准。

固定源码最终验收：95 项单元测试和82项真实 PG16 测试通过，无失败或跳过；包括39项购买与 Out 列表、26项会员定价、6项价格截断、8项商城分类及3项商城促销。两套完整 TypeScript 类型检查通过。真实 Out JWT、接口权限、受限 App 登录、访客商城隔离、筛选交集、分页和搜索历史不写入均有数据库验证。每个隔离数据库均报告零残留 fixture 并停止。此前将两套原生结算测试放进轻量数据库执行时因购买来源表缺失产生9项失败；原始失败记录保留在本地验收目录，最终将完整测试放回既有原生运行器并全部通过。
