# 新闻公告、图片热区与活动四卡作者迁移

本批在实际 Admin「DIY 装修 / 自定义页面」接入 `news`、`hotspot`、`activeParty` 的新增、删除、排序、逐项编辑、图库／链接选择及原页面保存。PHP → TypeScript 整体迁移继续开放。

## PHP 合同与当前消费边界

来源固定为 PHP `8ed2a5b139f9170dd11b0dff91803f2fd59e40a5`。`home_news_roll.vue`、`home_hotspot.vue`、`home_hot.vue` 的完整静态默认对象分别为 32、14、10 个顶层字段，包括标签及表单元数据。只在明确新增时生成默认值，不对导入对象自动合并、截断或重排。原面板的 `setUp.tabVal`、`c_title`、`listConfig.tabCur` 作为作者界面元数据保留，新界面统一展开编辑。

公告承接标题图片／文字、滚动／列表、滚动方向、更多按钮与链接、逐条显隐、主题／自定义色、渐变及全部边距圆角。活动四卡承接旧 PHP Admin 的标题、徽标、四卡内容／图片／链接及颜色；旧 PHP UniApp 没有 `activeParty` 渲染器，本批使用现有 TS 消费者，不声称与不存在的 PHP Uni 实现逐像素等价，也没有新增活动目录 API。

普通新增分别受现 TS 消费容量 10 条公告、4 张活动卡、30 个热区限制。30 是现 TS 的容量，不能归因于原 PHP。超量、隐藏、异常和未知导入条目完整保留，超量项仍可选择、编辑、排序或明确删除。超过控件普通范围的导入数值和长标题在挂载、未变化事件及修改其它字段时不被自动重写。

热区坐标采用 750 设计宽度，真实高度来自实际加载图片的自然尺寸。加载之前不允许修改几何位置；框选、反向框选、拖动和右下角缩放均更新四个坐标，保留 `number`、`nowImgWidth`、链接和未知元数据。组件、底图、选择项、账号／编辑会话变化及卸载会撤销旧手势。明确选择不同底图清空区域，同一素材的签名续期保留区域。独立只读预览应用公开消费者的间距、背景与圆角，并在自然尺寸加载后裁切有效链接区域，预览不执行链接。

公告原图 `news2.png` 原字节同时复制到 Admin public 与 UniApp static：57×48、3,212 字节，SHA-256 `be7896ba5fa4acbf4156901229761c19eedc364a54973a1c6f1872c1f856b98f`。

## 本批追加的消费修正

回查 PHP Uni 源码确认 `follow` 的独立圆角直接使用原数组 `[0,1,2,3]`。上批 Follow 作者报告记载的当时 TS `[0,1,3,2]` 保留为历史；本批同时修正公开消费者、后台投影及左右下角标签，不改导入数组。

公告滚动样式在主题色调下使用白色标题文字及纯主题背景；自定义色调仍使用作者标题色与渐变。公告列表标题的原合同保持。新闻／热区圆角继续使用 `[0,1,3,2]`。

三族作者共用链接选择器提供已注册页面、HTTP／HTTPS 网页和 `path@APPID=wx…` 外部小程序。本批为公告与活动消费者接入现有受校验的平台跳转器，使这些已提供的目标具有实际平台结果；H5 使用安全网页打开方式，App／小程序网页使用既有 WebView，小程序目标仅在支持的平台执行。过期身份、配置、隐藏状态或卸载后的失败回调不再作用于新会话。没有改写通用全站链接解析器。

## 媒体、保存与审计

图库使用既有附件查看权限，内容编辑使用既有 `dise.manage`。保存只规范公告图片、热区底图和全部导入活动卡图片的明确槽位，临时附件签名不写入这些槽位；未知字段及独立 `content` 保留。导入公开 HTTP 图片按现消费者升级为 HTTPS，安全内嵌图片仍可只读显示；私有附件需要与当前稳定引用一致的有效票据。

外部替换 JSON 或显式会话事件推进独立的画布上下文代次。即使仍使用同一公开图片，旧加载回调也失效，并重新加载、上报自然尺寸，避免父编辑器已撤销尺寸后拖拽不能保存；自身正常提交及条目选择仍保留当前有效图片尺寸。

已发布图片预览复用匿名 `GET /api/diy/get_diy/:id`，先比对完整规范组件再逐槽核对素材。匹配 `activeParty` 时仅去除原公开兼容层实际移除的 `titleConfig.place/max` 和 `desConfig.place/max`，其它元数据变化必须拒绝。旧账号、页面、发布状态、条目、组件及会话的异步回执不能向当前编辑器授予预览。

本批没有新增服务端路由、权限或 DDL。API 清单保持 703 个已审计 Axios 调用点、741 个变体；新增的显式图片预览 fetch 复用上述既有公开 GET，不能表述为「没有新增任何前端调用」。[源码与完整清单追加层](../audit/diy-editorial-author-source-binding-20261024.json)保留上一批完整报告和所有旧基线，通过精确逆变换验证三处 DiseList 接入；[PHP 样式及消费修正证据](../audit/diy-editorial-author-php-parity-20261024.json)单独绑定实际消费者和作者源码。

现有其它聊天的会员权益作者改动原样保留。本批没有提交、合并或部署；本地夹具不代表生产 ACL、PostgreSQL／R2 或真实微信设备验收。
