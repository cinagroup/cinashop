# Out 商品会员价和独立佣金

固定 PHP `8ed2a5b139f9170dd11b0dff91803f2fd59e40a5` 的 `Product::productSave`、`StoreProductServices::saveData` 与 `StoreProductAttrServices::validateProductAttr` 使用 `is_sub` 数组表达两项独立开关：`0` 为会员价，`1` 为 SKU 独立佣金。本批在 Out 实物、手工虚拟及次卡商品作者中接通两项开关，分别写入 `is_vip`、`is_sub`。启用会员价时所有 SKU 须提供大于零的会员价；关闭独立佣金时先清零两级 SKU 佣金，再执行金额校验。独立佣金开启时两级金额之和不得高于 SKU 原价。

为兼容历史 Out 客户端和已持久化的幂等回执，省略 `is_sub` 保留已有商品开关，旧请求的规范化形态不变；显式空数组会关闭两项开关并清零佣金。显式选择、SKU 金额和其他写入一同参与请求哈希。写入同一事务锁定 SKU 和商品行，编辑保留库存；提交前核对开关、SKU 金额与回执，延迟约束导致改写时整笔回滚。详情通过既有旧格式投影返回数组。

真实隔离 PostgreSQL 下，会员商品生成应付 7.50 元的未支付订单，并快照一级 2.00 元、二级 1.00 元独立佣金；关闭会员价后的旧确认必须重新确认。并发测试覆盖结算等待 SKU 锁时会员价或佣金发生修改，避免按旧规则扣库存。受限应用登录使用既有权限计划完成作者写入。此处不调用真实支付或第三方提供方，不部署，不上传旧 PHP；卡密和优惠券商品的 Out 作者仍待迁移。

上一批 GitHub CI 的两个 Worker 分片在测试前无法检出固定旧 PHP 提交，远端返回 `not our ref`；本地验证使用同一已核对提交，不能代替该 CI 结果。既有私有 schema 核销成熟测试在未修改基线与上一批均有两项通知合同失败，非本批通过项。

固定源码验收：231项单元测试、190项真实 PostgreSQL 测试全部通过，无跳过。数据库覆盖author 65项、member 14项、brokerage 40项、checkout 71项；结算并发文件首次在固定时限内超时，生成的隔离集群已核实停止并清理，随后按测试声明分为七组覆盖全部71项。各分组及其他通过的隔离数据库均零残留并停止。两组类型检查覆盖原配置全部4342个根文件，编译选项相同；独立运行时类型检查通过。单次完整项目检查此前两次达到既定8 GiB堆上限，因此保持上限并采用完整覆盖的分组。
