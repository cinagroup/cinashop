# Supplier 商品品牌选择、保存与回读

PHP 实际商品编辑抽屉用可逐级选择的品牌 Cascader 提交完整根到当前品牌路径。旧控件的 initBran 会递归把编号转成字符串；后端兼容规范的正整数十进制字符串与整数，归一后检查重复、父子链、最多16级和CSV最多64字符。新 TypeScript 控件发送数字路径，仍可选择根、子级或孙级。

显式 brand_id=[] 清空，省略则不修改主表 brand_id、brand_com 或 type=2 关系。主表保存末级编号及完整CSV，各级关系保持 status=1、relation_pid=0。只有平台、显示、未删除且父链完整的品牌可以新绑定。真实品牌行按编号锁定，目录变更争用返回409；保存继续下架并重置待审，不能借品牌编辑批准商品。

读取返回数字路径和原始编号、CSV、一致性及可选性。缺失、隐藏、格式错误或关联矛盾的历史品牌仍允许读取整个商品；界面显示原绑定并允许明确替换或清空。未修改品牌时，目录加载失败不妨碍保存其他字段。复制继续继承来源品牌，创建后再从普通编辑页调整。

新品牌写入只拥有两列与 type=2 关系。完整商品行、原有定时计划及其他隐藏关系在保存末端核对；跳过、改写和延后触发器异常均回滚。本次显式品牌操作在返回前执行 SET CONSTRAINTS ALL IMMEDIATE，结算当前事务延后约束；不宣称对任意嵌套调用者的约束延后模式透明。旧请求省略品牌时不执行该语句。现有编辑GET由成熟多次查询组成，不宣称重复读快照。
