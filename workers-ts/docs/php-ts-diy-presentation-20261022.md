## 作者和客户端合同

使用 PHP 实际持久结构，而非自创通用面板。标题保留更多按钮开关、隐藏更多时的三种对齐、普通/斜体/粗体、两种字号、标题与按钮颜色和渐变。空白保留完整高度及独立内外背景，超过旧通用 300 上限的值不截断。辅助线保留虚线/实线/点线及独立内外间距。富文本的 `udConfig` 是顶部 margin，内部 padding 为 30rpx；视频三种比例分别为 9/16、3/4、1，并使用每个实例实测容器宽度。四角按 PHP 实际客户端左上、右上、右下、左下顺序，不套用上一页脚合同。

新的小型 Admin 编辑器可选择、添加、删除和在本族中排序，逐字段修改完整原始数组；其它组件、未知字段、独立 content 和不可变行元数据保留。视频库复用实际附件分类、分页、搜索和 file_type=2，封面复用原图片选择器；上传复用既有平台 MP4 分片服务。ProductVideoUploader 仅增加默认“商品”的可选 subjectLabel，并让本编辑器显示“页面”；逐字 inverse 可重建原上传、会话和 ACL 代码。

导入配置中的严格非负数字字符串与数字采用同一读投影，字号、高度和四角预览保持一致；只读预览不会把原始字符串自动改写成数字。仅用户明确编辑的字段才进入对应 setter。

## HTML、媒体与生命周期

DIY 使用独立有界 HTML 解析器，原文章和活动净化器保持原值。保留引号中的 `>`、真实首个 src 属性、注释和作者无关字节；仅实际 `img[src]`/`video[src]` 可进入媒体投影。href、source、poster、srcset、预览字段和被禁止命名空间的后代不获得素材权限。HTML 属性只解码一次，JSON URL 不作 HTML 解码；双重编码不能变成本地附件权限。公开内容重建安全标签、属性和样式，拒绝事件、脚本、任意 URL CSS 和危险协议；签名后再次净化以免被拒素材留下空 src。

视频只接受当前平台 type1/relation0/module1/fileType2/R2 imageType8、真实 Admin UUIDv4 MP4 key、当前 attDir 和 video/mp4 MIME。用户、供应商、私有、删除、变更 MIME/key 和错误类型均不能因旧票据而恢复权威。图片复用既有平台 raster 判定。新 JSON/HTML URL 长度 4096 独立于旧目录图片 255 字符限制，不放宽旧槽位。

原普通 2500、导航 20000、页脚 20000 容量保持；新族另有完整 20000 槽位，每次 owner 查询批次最多 10000，HTML 100000 token、64 层和最多 10000 真实媒体。先完整校验预算及所有 owner，再按 256 个素材批次签名，全部成功后一次提交；后批 HMAC 失败不得留下前批局部修改。作者 HTML 2MB、读取 HTML 4MB（容纳签名展开），实际 Admin 总 JSON 仍是原 2MB。

富文本使用平衡的类型树，仅交互祖先改为原生组件，避免按视频或链接切碎段落、列表和表格。实际锚点复用已有合法导航，视频原生 controls 不自动播放。auth、token、session、页面 active、schema、刷新与站点关闭均撤销旧回调；重试绑定单次 attempt。相同作者媒体的票据轮换只保留 seek 位置，播放要求新的用户手势；真实作者/owner/隐藏/关闭变化清除位置。过期会撤销整个媒体渲染，旧 DOM 不得继续工作。

原生交互分支保留标题语义、mark/code/pre、安全作者样式及有序列表 start/type；表格为包含被动单元格的实际网格，保留 colspan/rowspan、表头与节顺序。就近锚点继承和被动子树 rich-text 同时验证。这个有界转换器不实现完整浏览器的畸形表格修复算法；H5 几何验收不代替 MP/App 真机网格验收。已有合法 tel 链接由本族就绪门禁进入原有电话能力，本轮未在浏览器触发实际拨号。

raw-text 容器以真实闭合边界结束，内部伪造的损坏 img 引号不能吞掉后续合法正文；plaintext 消费其后全部文本。媒体映射先收集完整回调结果，再一次拼接，保留无关作者字节，并用实际 10000 槽位边界核对完整输出。

平台说明依据 [UniApp rich-text](https://uniapp.dcloud.net.cn/component/rich-text.html) 和 [video](https://uniapp.dcloud.net.cn/component/video.html)。MP/App 的构建和 Node 适配验证不等于真机播放或外部导航验收。
