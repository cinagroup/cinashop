## 原始范围与身份

旧 `view/admin/src/pages/setting/devise/fab.vue`、`components/linkaddress/index.vue`、Diy 服务及真实悬浮组件为范围依据。保存六个根键：`is_show`、`index`、`shifting`、`main_ago_image`、`main_after_image`、有序 `button`。子按钮消费 `img/url`，其余可精确保留的历史扩展属性随对应按钮重排保留；不要求不存在的子按钮名称或标题。

- 样式一、二允许 **0–5** 个子按钮，主按钮前图必填，后图清空。
- 样式三要求 **3–5** 个子按钮，主按钮前后图均必填。
- 样式四要求 **3–5** 个子按钮，不使用主按钮图片，两图明确清空。
- 显示开关为 0/1；上下偏移为 **0–100 整数**，按实际组件高度约束边缘位置。隐藏配置也须满足完整输入合同。
- 图片使用稳定引用与平台素材权威，预览可以签名，不把短期预览地址回写。

配置由 `template_name=suspended_window` 与 `type=3` 识别，安装行号不是权威。旧 seed 行的 `status/is_show` 均为 0，但 JSON 内 `is_show=1`；三者不能混用。归一后相同的模板别名、重复行、错误类型及删除标记须诊断，不自动挑最大 ID 或重新插入。GET 不初始化；真正缺行经显式、有版本的保存初始化。坏 JSON、无法精确保留的扩展数值等历史对象不自动覆盖，维护修复继续独立进行。

## 管理与消费边界

现代双 Admin 前缀各五项接口：

| 方法 | `/adminapi` 后路径 | 用途 |
| --- | --- | --- |
| GET | `/setting/fab` | 有界快照、版本、原值诊断与素材预览 |
| POST | `/setting/fab` | 完整配置保存或显式缺行初始化 |
| GET | `/setting/fab/request/:requestId` | 原请求回执 |
| GET | `/setting/fab/link-categories` | 专用链接选择器分类 |
| GET | `/setting/fab/link-targets` | 必要目标资料、搜索与分页 |

另一前缀为 `/api/admin`。公开消费仍使用已有 `/api/diy/get_suspended` 与 `/api/v1/diy/get_suspended`，委托共同配置、链接与素材读取合同。本批不开放无版本的旧 Admin 保存别名。

独立 `fab_settings.view/manage`，manage 蕴含 view；旧菜单 1612 只有 `menu_path=/admin/setting/pages/fab`、`unique_auth=setting-system-fab`、正确页面类型及可访问状态成对匹配时映射 view。广域 config、dise 或素材权限不代授。通用 `/dise/save` 必须在已锁行上检查模板与类型，拒绝修改 FAB/专用可视化配置；前端取消相应通用编辑入口。

保存绑定管理员、UUID、全集版本及规范载荷摘要；旧按钮使用当前快照中的来源标识合并扩展属性，新按钮明确为新项。回执重放先于版本校验。读取用有界只读一致快照；写入在明确 READ COMMITTED 中先取得目录锁，再校验最新快照与素材共享锁，配置与操作回执原子提交。没有 HTTP DDL、权限修补或外部 provider 调用。

只有匹配原请求的真实 HTTP 409 `FAB_SETTINGS_STALE_VERSION` 或写入前校验、成功回滚后的真实 HTTP 400 `FAB_SETTINGS_REJECTED` 可以释放待确认状态。裸错、超时、日志冲突及写入后失败不提供此证明。后台保留原字段、原请求与身份隔离的待确认状态；确认重读后才生成新请求。旧来源无法唯一对应时，要求用户明确选择保留哪个当前按钮的附加设置。

Uniapp 四种样式分别实现布局、开合、主图切换、拖动和滚动收起，样式二保持侧边交互。按 0/100 与实际高度处理位置；公开投影保留安全兄弟按钮的顺序，对无效链接或素材明确禁用，不输出原始扩展属性、管理员来源标识或模板行资料。
