# Supplier 只读商品详情

PHP 商品列表的“详情”打开 productDetails 五页签抽屉，抽屉还包含保存行为。TS 补充独立只读页面 `/products/:id/view`，商品列表的查看权限账号可进入，管理权限账号可另行进入原编辑页。这里完成的是基本商品、当前规格、库存、配送、售后和媒体的只读消费；不将整个旧编辑抽屉或全部 PHP 功能标为迁移完成。

`GET /supplierapi/product/product/:id/view` 不接受查询参数。真实 JWT 对应的当前账号、供应商、口令版本、有效期与 product.view 在 REPEATABLE READ／READ ONLY 中核对；只读取本店 type=2、非回收商品。普通受限 LOGIN 仅需 auth 四表、product、attr、attr_value、description、attachment 九表 SELECT，无 DML 或序列能力。各表与授权在同一快照；实际行所有权与商品维度不能借用平台、其他供应商或活动记录。

返回闭合九项 data：版本、账号、供应商、商品编号、三十项商品资料、维度、十项当前SKU、媒体、bounded。仅 active SKU，顺序固定，最多500；最多16组维度、每组100值、轮播10、媒体640、已消毒详情400000字符及完整JSON2MiB。超出边界明确失败，不悄悄截断。金额支持数据库十八位整数、两位小数，前端按字符串分组，不转 Number 丢失价格。商品类型按实际 schema 展示：2优惠券、3虚拟商品、4次卡。

现代只读投影不查询或返回卡密、固定交付正文、卡号密码、SKU unique/code、成本／结算／佣金或退役规格。原编辑 GET 与 ProductForm、管理服务和原保存行为保持。该读取面不提供管理写入、上传或导出能力；次卡等未受现有编辑器支持的类型仅展示。

图片复用已有本店媒体授权。仅已登记并属于本店的合法图像、可用视频返回规范短期票据，外店图片占位；canonical description_html 在服务端消毒，前端只解析一次原引用并使用对应媒体投影，避免二次解释已签名HTML。票据到期或图片失败后只占位，手动刷新详情再取；不自动读取或重试写入。已签发票据在到期前仍是 bearer capability。

前端绑定当前路由、实际账号、供应商和权限；无效／重复／不支持的查询或商品编号不退到其他商品。刷新先清空原资料；路由、真实会话 A→B→A、存储事件、撤权、卸载取消在途或 Axios 排队 GET，旧响应不得回填。只读账号无编辑入口，页面没有业务写请求；评价入口复用已完成的当前商品评价页。开发 preview=1 保持独立模拟，生产拒绝该参数。

验证通过数、初轮夹具复合键类型错误及修复、类型3/4名称纠正、真实PG／IAB和GitHub终态以本批审计为准。合成视频文件仅用于授权和票据验证，不代表可解码播放验收；图片通过真实本机对象绑定读取。整体迁移保持 active，不执行生产DDL、GRANT、部署或真实provider调用。
