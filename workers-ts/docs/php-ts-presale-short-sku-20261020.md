加购控制器保留非预售既有 trim 行为，同时携带原始输入供预售分派严格校验；显式 type6 与默认 type0 当前转预售均不能把非法输入洗成有效身份。历史购物车/原订单别名不做修补。新 type6 商品行与快照冻结同一规范键；原始数据库值和库存 CAS、旧原购/实物原购/取消/支付账本协议及编号 SQL 不变，不回填旧凭据。
