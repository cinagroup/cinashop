# 社区帖子互动与详情访问统一

本轮基于 `d81c81670eb090264db195988a848899fc668dd3`，补齐主列表、作者工作台、话题／搜索及两个视频入口的帖子点赞、取消点赞、分享与互动状态核对。作者的“赞过”列表在取消点赞后重新读取成员，主列表和关注动态条带在换号、隐藏及迟到响应时清除或隔离旧状态。旧 `discoverDetails/index` 已增加实际注册的本地桥接页；规范图文链接进入非底部标签的 `workspace?id=`，视频进入 `discoverVideo/index?id=`，保留有效来源参数。

新增可选鉴权的 `GET /api/community/state/:id`，返回与详情相同的帖子投影和当前观看者标记，HTTP 详情及状态额外返回实际的 `site_url` 配置；严格 HTTPS origin 校验由分享适配器执行。状态读取通过现有纯可见性规则，只允许公开帖子或真实 `type=2` 作者预览自己的未公开帖子，不因数字编号相同而认可门店或虚拟作者身份。状态接口在短事务内持有目标行共享锁，并通过同一事务完成投影，避免点赞标记与帖子计数在竞争期间混合；它不修改业务行或序列。这不等于 PostgreSQL `READ ONLY` 事务、全库可重复读快照或数据库物理零写。

正常打开公开详情只记录一次浏览；本人未公开预览不记录浏览。互动刷新、分享前读取、原帖编辑装载及媒体重新取签名均使用只读状态接口，不再以详情读取代替刷新。无编号视频入口在列表首项确认访问后才显示活动视频；显式编号入口先读取状态校验类型／作者，再记录一次实际访问。打开视频评论面板复用已访问的视频，不额外增加浏览。详情、状态和兼容写接口 `GET /community/share/:id` 返回 `Cache-Control: no-store`；既有点赞别名及强鉴权分享合同保持，未修改 `/api/get_script` 的已恢复行为或全局缓存。

点赞发送明确的目标状态，使用服务端返回的计数。重复目标状态保持幂等，历史重复点赞关系在取消时全部移除但只回退一次计数，历史零计数不会变负。作者计数按类型和身份精确更新；既有同一规范身份存在多份有效档案时同步更新的策略保持，本轮不借机新增生产唯一性约束。隐藏、待审核或删除的父帖不能进行公开互动写入。

分享按平台区分事实：H5 使用当前可信同源页面生成规范链接，真实剪贴板成功后，已登录用户才调用兼容分享接口记录一次意图；App 仅使用配置的严格 HTTPS 前台站点 origin，不回退到 Worker API 域名或硬编码网页地址，并核对实际原生微信服务与回调；小程序返回固定帖子身份的消息／朋友圈材料，材料已提供不表示对方已收到。匿名用户可对公开帖复制链接或取得平台分享材料，但不调用强鉴权分享接口，页面明确说明不记录分享次数。旧匿名链接的 `spid=0` 可读取并归一为无推荐来源，帖子 ID 仍必须是有界正整数。无配置、复制失败、能力缺失、原生取消及重复回调均不伪称分享成功；重复 provider 回调只发起一次原生分享，迟到失败回调不能清除已经进入服务端阶段的保护。

网络、5xx 或无效成功体被视为结果未知。界面保留互动锁，不自动重发点赞或分享；在同一 auth store 内关闭／重开详情、分享面板或重建组件，仍须主动通过只读状态核对后才能再次写入。浏览器实测还纠正了未知状态下分享入口被整体禁用的问题：未知状态仍可打开只读分享面板，其状态预读不会解除未知标记；点赞和复制分享继续锁定，直到用户主动刷新互动状态。打开面板本身不记录分享次数。跨账号、同 UID 凭据替换、会话版本和页面生命周期约束迟到回执。registry 是瞬态的同会话投影，保存互动 nonce、计数及用于归属比较的会话身份；会话身份仅用于归属比较。该 registry 不缓存帖子正文或草稿，也不承诺跨硬刷新、跨标签或真实设备的持久幂等。

浏览器实测发现分享面板的关闭按钮曾落在 H5 底部 tabbar 下方，已将遮罩底边按 `var(--window-bottom, 0px)` 向上留出窗口底部区域，保持原有层级。当前 UniApp H5 的该变量已经包含 tabbar 高度及安全区，因此 H5 不再叠加 `env(safe-area-inset-bottom)`；非 H5 面板通过条件样式增加安全区内边距，并保留前置普通内边距作为不支持该表达式时的回退。这项 H5 实测不能替代 MP／App 真机对原生 tabbar 和安全区的验收，最终完整浏览器结果另行记录。
