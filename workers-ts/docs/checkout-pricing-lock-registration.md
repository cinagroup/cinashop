## 同一安装定义的三个入口

| 入口 | 本次注册 |
| --- | --- |
| 外部 SQL | `migrations/0160_checkout_pricing_lock.sql` |
| 内嵌编号迁移 | `MigrationService` 第 0166 步，合计 167 步 |
| 显式维护安装器 | `installCheckoutPricingLock` / `runCheckoutPricingLockSchema` |

`checkoutPricingLockInstallation.ts` 从共享的目录查询和函数正文生成无参数安装 SQL；外部文件与内嵌 SQL 有逐字相等测试。安装器与编号迁移使用同一 SQL，不另维护宽松版本。0166 在独立根事务执行，前序失败不调用它；本步失败不记录已完成，不能按“已存在”错误跳过。

安装事务保留更严格的超时，固定 `pg_catalog,pg_temp` 搜索路径，使用专用 advisory gate 和两张表的 ACCESS EXCLUSIVE NOWAIT。首次安装原子完成固定函数、所有权和授权调整；重复执行必须完整匹配既有协议，保留函数 OID/ACL 和数据，不覆盖漂移。

## 显式维护身份与角色供应

必须事先供应独立受限 NOLOGIN 所有者。应用安装器、外部 SQL 和编号迁移**都不会创建角色、生成口令或猜测所有者**。拒绝管理属性、成员关系、额外对象所有权/写权限及现存登录连接；不能把活跃业务账号改成 NOLOGIN 后充当所有者。

- 显式 TypeScript 安装器接收已审核的所有者名称，在自己的事务内设置 `cinashop.checkout_pricing_owner`。
- 外部 SQL 要求执行它的同一维护事务已经显式设置该参数；应与迁移放在同一个 READ COMMITTED、可写事务内。
- 编号根运行器不选取所有者，要求实际承载其事务的维护连接已有此明确配置。连接池中另一连接的设置不能代替它；不得依赖“先在任意连接 SET 一次”。正式迁移连接的供应方式仍待接入验收。
- 缺失/非法/不存在的所有者、协议漂移、错误隔离级别、只读事务或维护竞争均失败关闭，不留下部分函数或授权。
- 安装只给专用函数所有者锁表所需的两表 UPDATE 权限，创建期间短暂的 schema CREATE 会撤销。**不会向业务登录授予配置写权或函数执行权**；业务 SELECT/精确函数 EXECUTE 必须另行审核、授权并用实际独立登录执行 `--checkout` 只读预检。

完整迁移测试显式使用 `checkoutPricingMigrationDatabase`：仅为本例创建随机 NOLOGIN 所有者、配置单连接、退出时删除自有对象和角色。通用 `sequenceRunnerDatabase` 没有自动加权或回退生产。只运行普通 ORM 表结构生成并不会自动安装权限协议；审计中的七条 ORM 路径在建表后显式调用安装器。
