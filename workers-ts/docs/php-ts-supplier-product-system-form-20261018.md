# Supplier 商品自定义留言模板

普通商品新建／编辑补齐启用、选择平台启用模板、预览字段名称／类型／必填、保存回读及关闭。依据实际 PHP Supplier 抽屉 productDetails.vue:1103–1126、1163–1169、2136–2150、2284–2287、3152–3153。原自由 custom_form 作者在 PHP 1128–1160 已注释，本次不恢复；关闭只保存 system_form_id=0，历史客户答案及商品旧 custom_form 原文保持。

沿用现有 GET /supplierapi/form/all_system_form 和 GET /supplierapi/form/info/:id。目录仍为全局启用且未删除的 id/name，最多500项，达到上限明确提示可能还有未列出模板；不宣称完整枚举。详情仍由成熟元数据接口返回完整十字段定义，界面经订单共享解析器严格核验后只展示名称、类型及必填，不展示默认答案。该接口传输不是有界投影，也不宣称编辑GET为一致快照。空定义、未知组件、重复组件键及超过100项／1MB定义均拒绝成为新选择。

普通 POST 可选 system_form_id 接受非负 int4 数字或规范十进制字符串。省略时 SQL UPDATE 完全不提及该列；0明确关闭，正数要求当前全局模板启用、未删除且能够被真实订单解析器接受。GET 增加非负展示 ID 与闭合二字段 system_form_selection（真实原ID、available）；负数、缺失、停用或坏定义的历史绑定仍可读取、保留或明确修复，SQL读取失败不会被伪装成不可用。

显式修改重查当前 JWT、口令、有效期、供应商及 manage 权限，沿用分类／商品写屏障，以实际模板 SHARE NOWAIT 保护获准定义。品牌、保障、参数等同次作者执行后才写入本列，再结算 SET CONSTRAINTS ALL IMMEDIATE，重查完整商品行、全部有界关系及获准模板的有界字段快照；最后留言列作者结束后还会重查同次选择的保障原获准完整行及品牌路径资格，防止该作者的触发器使前序绑定失去资格；原合法停用保障仍可保留。相关并发、跳过或篡改触发器返回409并整笔回滚。商品保存仍下架待审，不代替管理员审核。模板 value/default_value 比较各限1MB；不宣称任意超长未消费元数据或任意外层延后模式透明。

界面目录失败且未修改绑定时允许保存其它资料；明确关闭不依赖目录成功。修改绑定或新启用后，未选有效模板或尚未完成预览时阻止保存；未修改旧绑定时仍允许保存其它资料。路由、卸载、真实存储会话 ABA 和内存身份／权限变化取消在途及排队请求，恢复旧权限不能复活旧表单。取消请求不能撤回已提交保存，普通保存没有新增复制专用 UUID 恢复协议；完整复制继续使用成熟来源和隐藏字段规则。

原生验收使用真实 App／Customer JWT，从 Supplier 绑定到顾客确认、必填拒绝、成功创建和答案快照，再关闭模板后创建第二订单并核对旧答案不变；配置与确认缓存使用内存 CONFIG_KV，编号 Sequence DO 使用本机合成实现。Supplier 受限账号没有 system_form_data 答案表权限。浏览器验收范围是生产 Supplier 页面，客户下单证据单列为原生 HTTP 链，不能互相替代。

用户确认保留已恢复的 PHP 兼容 /api/get_script 及三端加载器；相关退役审计裁决保持。实际测试、构建、浏览器、历史失败、清理和 GitHub 发布状态见同名审计 JSON。完整商品编辑器与整体 PHP→TS 迁移继续进行，本批不声明整体完成。
