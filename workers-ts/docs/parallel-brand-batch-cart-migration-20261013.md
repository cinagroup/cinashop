# 品牌、供应商批处理与购物车计算并行迁移

2026-10-13，本地候选已验证，未发布。整体 PHP → TypeScript 迁移继续进行，迁移父项保持开放。

## 本批行为

- 后台品牌恢复六条可读 PHP 合同，因可选 cascader 类型注册七条 TS 路由。支持三级品牌、懒加载、父链选择、排序／显示和删除；引用中的子树可移动，原子调整已知完整商品品牌链与关系，保持主品牌和明确的独立选择。冲突、异常历史关系及不完整审计回执拒绝整笔操作。平台目录限定 `store_id=0`，不为旧表虚构 Logo 字段。
- 供应商原 `batch_process` 恢复旧页面的四类操作：分类、物流、自定义表单和运费。支持明确选中与有界筛选全部，预览与提交核对原目标集合；授权、商品、分类及有效表单／运费模板按成熟协议锁定。完整商品行回读及审计回执确保未选字段不会被触发器悄悄修改。现代页面保留未知结果与原请求，核对后才能完成。
- `POST /api/cart/compute` 使用选中购物车 ID，在真实用户身份和 PostgreSQL `REPEATABLE READ, READ ONLY` 中计算会员、促销、首单及最大可用／可领取券优惠。预算不生成订单键、占库存、领券或开通会员。前端明确领取后，以真实 owned 券 ID进入成熟订单券选择与确认；数量、履约、页面隐藏和身份变化撤回旧结果。
- 合法 `numeric(12,2)` 单价 `9999999900.79`、数量 `3478` 的浮点原价曾为 `34779999654947.63`，实际整数分为 `34779999654947.62`，并导致成熟列表校验拒绝。cart／buy／compute 原价现统一整数分，所有模式检查安全整数范围；预算 DTO复用成熟14位整数金额合同。
- 标签和品牌未知保存结果的恢复按钮移入保留弹窗，真实按钮能重试原内容或核对已保存事实。标签 Vue reactive pending 改用明确 DTO复制，避免 `structuredClone` 抛出 `DataCloneError`；证明成功才关闭原弹窗。

详细合同与已知范围见 [品牌模块](admin-product-brand-catalog-20261013.md)、[供应商批处理](supplier-product-batch-management.md) 和 [购物车计算](cart-computation-contract-20261013.md)。

## 失败与修复

保留了根部锁函数类型断言换行的首次解析失败、标签 reactive clone失败、供应商活跃表单夹具误设为禁用、缺失审计回执／未选字段触发器回归、UniApp不完整依赖导致的 `entities` 解析失败，以及浏览器图片选择器错误。严格 `npm ci` 修复依赖，没有修改锁文件来绕过失败。

品牌原生最后用例曾持有审计屏障并同步等待同一商品锁，形成测试自身等待环，触发生产2秒锁等待预算。修复仅改变测试同步：独立连接证明商品锁正在等待及品牌行NOWAIT拒绝，先释放屏障，再核对两事务提交后的新父链、价格和关系。生产超时、锁协议和业务断言保持。
