# Supplier 商品参数编辑与完整复制

PHP 实际 Supplier 商品编辑抽屉选择 all_specs 模板填入初始行，允许改名、增删和值／整数排序编辑。模板并非永久的参数名称白名单；清除模板选择不会清除已有行，服务端清除快照的旧代码亦已注释。TS 普通新建／编辑补齐此完整流程，区分“清除模板选择”和“清空全部参数”，复制页继续继承实际来源参数并在创建后开放普通编辑。

沿用现有 GET /supplierapi/product/all_specs：父项三字段 id/name/specs，子项九字段，平台0/0或本店2/id、group3/owner0、同归属启用子项。目录完整上限2000个父项及2000个子项，界面一次模板种入最多100行，超过时明确拒绝而非截断。保留现有父项不按 is_show 过滤的行为，不恢复 PHP 中被注释掉的跨租户目录泄漏。子项 id/temp_id仅为快照元数据，不提供修改参数目录的权力。

POST specs_id/specs 必须成对出现，缺省完全省略原两列与type6关系更新；0/[]明确清空，0与非空行允许作为自定义参数保存。模板ID及行id/temp_id接受非负int4数字或规范十进制字符串，默认行元数据为0。排序接受有符号int4数字或规范字符串，默认0；名称允许重复。每行按PHP交集投影成id/temp_id/name/value/sort五字段，丢弃目录和其它未知键；name/value是原文字符串，检查trim非空但不去除原空格，保留PHP服务器拒绝单独字符串“0”的实际行为。现代安全边界为最多100行、每项文字最多255个Unicode码点、拒绝控制字符、孤立UTF-16代理字符及非规范／溢出整数；PHP原服务并无这些完整边界，不宣称是逐字相同的旧校验。

GET 增加 specs_id、五字段数字行 specs，以及闭合五字段 specs_selection：实际旧specs_id、原始JSON文字或null、consistent、available、truncated。原始文字最多展示1,048,576个Unicode码点，截断不可成为写入权威；负历史模板ID在编辑投影显示0，元数据保留真实负值，允许明确修复。坏JSON、缺失／外店模板或错误type6关系仍可读取当前商品；不向调用方返回外店模板私有名。type6须在零模板时不存在，非零时唯一、ID匹配、status1及relation_pid0，当前快照须可完整规范化才具有一致性。读取沿用成熟商品行和多次查询，不宣称重复读快照，原文上限不是SQL传输上限。

显式参数保存重查当前JWT、口令、有效期、所属供应商和manage权限，使用原商品与分类屏障、实际模板SHARE NOWAIT锁及完整行／关系回读。只更新specsId/specs和type6，执行SET CONSTRAINTS ALL IMMEDIATE结算当前事务延后约束；与保障、品牌、标签、计划同次保存时先校验参数，再让后续步骤保护新的参数状态，避免互相覆盖。全部保障与品牌写入结束后再次比较获准模板完整行，防止后续同事务触发器改变模板归属。普通保存继续下架待审；不宣称任意嵌套调用者延后模式透明。

完整复制通过现有真实来源全状态HMAC和写入屏障后，从同一事务实际锁定的来源主行与type6重新派生进程内WeakMap授权。授权不可序列化，绑定事务、来源全部行、type6关系、实际获准模板、供应商和新目标0，贯穿Admin输入规范化、关联校验与最终回读。当前事务延后触发器结算后，再核对来源、模板完整行、保障当前归属及启用资格、审计和事件集合；任何改变均回滚，包括原UUID回执。只有合法新五字段快照及正模板的合法空快照可走此窄路径；四字段成熟快照、Admin和通用关联默认规则保持。它允许真正复制新编辑的重复名、改名、负排序及无模板快照；用户不能通过HTTP标志、隐藏字段覆盖或伪授权跳过校验。来源HMAC、safe白名单、UUID回执和原UUID恢复协议保持；不存在／外店模板和已停用保障仍受成熟新绑定资格约束。

详情参数消费的旧通用JSON上限100000个UTF-16单元不足以完整显示100行、每字段255个补充平面字符。仅参数入口使用1,048,576上限，所有其它JSON调用保留原值；仍检查100行、255码点、控制字符、重复JSON属性、有符号排序并返回闭合名称／值／排序投影。实际消费函数保留原空格，不trim。使用真实落库快照调用消费函数的证据不等于完整公开HTTP详情验收。

刷新目录保留当前编辑意图；目录失败且参数未改时仍可保存其它字段，清除模板后可保存自定义参数，明确清空不依赖目录成功。路由、卸载、真实存储会话ABA和内存身份／权限变化取消在途及Axios排队请求；内存权限恢复不能复活旧表单。取消浏览器请求不能撤回已提交的普通保存，普通保存未新增复制专用UUID恢复协议。

本批仅使用本机合成App/JWT、独立LOGIN PG16和实际生产构建浏览器，不执行生产DDL、授权、部署或真实provider调用。用户选定的已恢复PHP兼容get_script保持。实际验证、失败、输入差异、清理与发布状态见同名审计；完整商品编辑器和整体迁移仍在进行。
