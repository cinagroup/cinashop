优惠券保留五种布局和金额券／折扣券／零金额材料，style3 只有去领券中心的共享按钮，其余布局才显式领取。领取之前先保存 actor／issue 的持久意图；同账号同券的两个实例共享进行中与未知结果保护。只有匹配意图的明确业务拒绝可解除保护；超时、5xx、坏成功体、旧 owner 回执保持未知，隐藏、重建和刷新不重发 POST。只读持券核对可证明当前拥有，不能证明那次未知提交成功；false 或缺失不能解除未知。迟到回执只更新原账号日志，不写新页面、toast 或 finally 状态。服务器精确兼容旧 `couponId` 与现有 `id`，两者均存在必须有效且相等；保留真实库存／限领／来源／凭证和事务权威。

直播只在 MP 分支读取与展示四种布局、真实状态、主播和商品；插件导航使用远端 `room_id` 与仅含 `pid` 的编码参数。H5／App 不读取直播或调用插件。活动预览10项、直播50项、促销100项／12分组／100选择ID、导航500候选等上限明确；直播／促销超量有界预览提示。MP／App 构建与原生 API／适配器证明不替代真实设备和 provider 验收。
