# 商品标签与供应商分类并行迁移（2026-10-13）

本批恢复平台商品标签／分组的 15 条已核实 PHP 合同，以及供应商分类新增动态表单的 1 条缺失合同。供应商原已注册分类接口同时补齐旧 DTO、完整增删改查、三级移动、递归状态与商品引用保护。新增后台 `/label/products` 和供应商商品页分类管理流程。当前为已验证本地候选，整体 PHP → TypeScript 迁移继续推进，尚未发布。

## 业务结果

- 平台标签分组、文字／图片样式、排序、启停、商城展示和批量删除使用同一服务；旧标签选择接口及现代简化入口共用归属和引用保护。商品公开 badge 在响应时生成图片预览，长期引用不持久化签名。
- 供应商分类列表、级联选择、旧动态表单与现代树／详情分别返回已核实形状。整棵三级子树移动同步重算层级和商品关联；分类移动／删除与真实商品、SKU 保存遵守共同事务锁。旧创建和完整编辑省略状态时按 PHP 默认为隐藏。
- 真实 JWT、当前账号、密码版本、角色和旧数字菜单决定权限；菜单只使用已有列级锁能力，没有扩大语义写权限。撤权后页面清空草稿并停止旧会话写入，引用冲突和明确业务拒绝保留可恢复输入。

合同与边界详见[后台标签](admin-product-label-catalog-20261013.md)和[供应商分类](supplier-product-category-management.md)。独立复核发现并修正了旧标签表单正文 `id` 兼容、旧分类缺省隐藏状态，以及原生验证揭示的历史 `010`／`+10` 标签引用保护。
