# Admin 商品编辑读取增量（2026-10-15）

新增真正的 GET `/adminapi/product/product/:id`，与上一批已推送的完整保存事务配合。主商品、普通规格、目录、表单及权限在同一个 REPEATABLE READ / READ ONLY 快照读取，结束前用数据库时钟复查会话期限。完整六步编辑／复制界面和整个 PHP → TS 迁移仍开放。

## 读取合同

当前平台管理员、密码版本、角色引用和 `product.view` 在事务内验证，精确 seed620 可读但不能保存。返回 `private, no-store`。拒绝所有查询参数，ID0／不存在商品按旧接口报错；保留源接口对已删除及非平台归属商品的读取。静态规格模板选择器先于 `:id` 注册，避免被新路由遮蔽。

主表全部列按旧字段名回显，恢复源金额／布尔／CSV／JSON、上海日期、品牌路径、标签／赠券、当前系统表单、视频地址、配送模板与分类选择器语义。主表选择不与过时关系表合并。目录返回完整的受限集合，包含源合同允许的停用／删除运费模板历史；分类树采用当前明确的根节点投影，缺失的 PHP 树 helper 未被冒充为逐字等价。

SKU 来自真实普通属性和有效 SKU，保留稳定 ID／unique、库存、图片、价格、核销信息。旧快照不覆盖权威行。没有单规格 SKU 时仅返回标记为待修复的内存模板，不分配身份；多规格缺失、重复或组合不一致明确拒绝。GET 不重置主表、不修复属性、不写审计或序列。

卡密只查 `product_id / attr_unique / uid` 的聚合计数，不读取 `card_no / card_pwd` 或旧属性快照中的秘密；`virtual_list=[]`。固定交付 `disk_info` 仍按既有 `product.view` 边界返回，以避免整表保存清空真实内容，本接口不宣称全部交付秘密已脱敏。受信复制入口及复制时清除内容仍待接入。

响应为 `{tempList,cateList,productInfo,editor}`。旧 Vue 必需的 `custom_form / custom_form_info` 保留在 `productInfo`；新增加的历史表单快照、退役 SKU、描述预览放在独立的 `editor`。可编辑 HTML 保留原文及规范私有素材引用，只有预览做清理。私有图片按快照中的实际归属验证后签名。

## 容量与拒绝

两阶段 SQL 预检在完整文本进入 Worker 前统计实际字符串字节及保守行开销，所列商品、目录及选择元数据集合累计预算 1 MiB；每组最多10000行。卡密聚合不读取凭据。JSON 另限深度24、30000节点、数组1000项；系统表单100字段，规格最多三维／每维50值／总组合200，均在展开前拒绝溢出。

完整 `productInfo` 的实际 UTF-8 JSON 限768 KiB，最终响应限2 MiB。前者为旧表单提交时的 SKU／赠券等转换预留空间；它是显式收窄的编辑读取范围，不保证所有合法 POST、所有历史数据或后来变大的系统模板均可重新编辑。超过范围完整拒绝，不截断、不更改业务数据。已分类409／503用旧 Axios 可拒绝的业务信封返回，未知异常仍保留原边界。

独立复核发现的预览重复、SQL无界文本、表单展开及 owner1 消费转换问题已修正；复核原文、补充与失败尝试在[账本](../audit/php-ts-admin-product-read-20261015.json)保留。
