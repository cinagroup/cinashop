# Uni 显式选券立即购买迁移

普通商品新增“领券并购买”和“使用此券购买”，沿用实际 SKU、唯一原购买购物车、既有唯一领取入口和真实订单报价。结算严格核对当前账号、attempt、new1 普通商品 cart、商品、SKU、数量及实际筛券的发行券 cid；已知 owned ID 精确匹配，空 owned 提示只能由同一发行券的实际可用 owned 券补齐。

加购或领取结果未知时保留原意图，不重复发 POST、不借用其他相同商品购物车。原 server cart ID 先持久写入 sidecar，再检查共享恢复记录；领取仅核对原商品、原券与原 claim attempt。receipt 最大 ID 不视作可用券。原券无效会明确阻断，用户改选或不用原券的决定持久保存。建单未知仅显式重试原 key 和原 payload；成功导航后只清理匹配本次购买的已确认恢复记录。
