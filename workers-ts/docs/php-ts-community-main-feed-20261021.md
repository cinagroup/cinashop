# 主社区关注、发现与混合精选

本批以 `29010385346add0f1b497957fe10fe142ef406fe` 为基线，补齐主社区“关注／发现／精选”三个 tab，默认进入发现；话题在原列表内筛选，列表每页 10 条。成功后才提交页码与整页结果，短页结束，满页继续读取下一页；失败保留已有内容并重试原页，刷新清除话题和分页。原始结果长度决定终止，重复 ID 去重后不会提前停止。前端最多读取第 1001 页；该页满 10 条仍明确结束并显示浏览范围提示，不请求第 1002 页，也不改变后端既有页码合同。

关注页读取当前用户的关注帖子、关注摘要及推荐作者。游客仅显示登录引导，不调用受保护的关注／推荐辅助接口。关注帖子在分页前限定为平台类型 0／编号 0 或真实用户类型 2／正编号，真实用户账号须有效，避免异型同号占据分页。此限制只作用于关注条件，发现保留原公开帖子可见合同；已停用社区资料本身仍可读，不能写成所有作者资料都必须启用。推荐候选另要求启用的 canonical 资料及正内容计数，沿原顺序分页；每人增加 `community` 预览数组，最多三项，精确包含 `id/type/relation_id/content_type/title/image`。单次有界 LATERAL 查询按 star、时间、ID 取公开已审未删内容，私有封面经现有所有权校验和 Controller 的 APP_KEY 签名，异型或跨所有者引用不能取得能力。点击预览读取完整帖子或进入实际视频页，小预览不冒充完整帖子 DTO。

推荐作者关注发送显式目标状态 1，成功后刷新成员列表；未知回执不重发。主列表的关注标记在同一 auth store、同一所有者内存中跨 tab 和实例重建保留，必须主动读取对应作者资料核对。成功刷新、失败和 finally 均绑定发起操作的所有者、页面代次与 tab，迟到回执不能把旧提示或列表画到新上下文。

精选使用同一公开混合流，真实显示当前图文或视频，并复用成熟评论、点赞／取消与分享。每次明确用户激活只执行一次正常详情访问；程序设置 swiper current、列表追加、媒体状态读取、关闭后的恢复均不重复记浏览。用户到达已载末项时读取下一页；主动“下一条”若需等待分页，会在原所有者、选择和代次仍一致且新增成功后完成这次选择。关闭或隐藏后，恢复先重读列表，再用只读 state 核对此前选择；第 21 条等不在新第一页内的恢复项独立可见，明确提示当前分页从第一页重载，既不伪造页内成员和位置，也不额外访问。触摸切换与程序事件分别处理，未知访问结果也不能自动重放。

共享 availability、明确关闭后的内容清空、主动恢复、账号／隐藏／卸载与迟到读取保护保留。真正的 410010 且不是服务端 5xx 才算确定拒绝；503 携带相同业务码仍为未知，不退出登录。未知互动标记仍需手动核对，不因切 tab、重开详情或恢复社区自动重发；恢复使用 state，不用有浏览副作用的 detail。注册表保留瞬态所有者身份和操作标记，不缓存帖子内容或草稿；这不等于完全不保留凭证身份。已恢复的 get_script、全局登录错误合同及生产 SQL 文件／schema 保持。
