## 当前已实现

`resolveOrderCoupon` 复用原计算器并记录内部模板依赖，客户报价指纹仍使用原有 `quoteFacts`，没有新收款公式或可由客户端指定的权威字段。建单在已领取券原子占用之后，用 `assertCheckoutCouponTemplate` 获取所用模板的一行 SHARE NOWAIT 锁并重读，保持至整笔事务结束。

对于原计算实际使用的商品券（scopeType=2），现在先执行关系 ACCESS SHARE NOWAIT、模板关系锁有界预取和保护目录检查，再取得上述模板行锁，以**下一条独立语句**读取至多20001条关系，超过20000条拒绝。模板预取使用WHERE false FOR SHARE，并仅在该语句临时设置lock_timeout=1ms，以兼容SELECT＋单列UPDATE权限；成功后恢复调用者原超时，失败由整笔事务回滚恢复，不用后续SQL覆盖原异常。两种关系级锁与普通DML兼容，不是全表排他锁；会阻止TRUNCATE及不兼容DDL越过本次校验。初始读到的其它券类型、无券或原本不使用券的路径不新增关系协议依赖。

商品券的新集合与新编码必须按原规则一致，且解析后的有效集合等于原计算依赖；范围变化即使优惠金额相同也要求重新确认。重复ID、非正ID等被原解析器忽略的变化，或末行删除后编码回退仍等价时可通过（原始行数上限仍须满足）。没有改变优惠公式、客户quoteFacts或已成功订单幂等结果。

在已持有库存／券等业务锁后不长时间等待反向模板写者：仅将 SQLSTATE 55P03 转为可重新确认的业务拒绝，死锁、超时、连接异常等其它错误原样传播。商品关系LOCK使用NOWAIT，模板零行FOR SHARE的隐式关系锁使用1ms有界等待，实际模板行锁仍为NOWAIT；不承诺所有目录查询永不等待。根客户端被拒绝。行锁也会暂时阻塞只改名称／计数的写者，但已提交的无关编辑本身不使报价失效。

目录检查不缓存ready，每次验证READ COMMITTED、当前复制角色、同schema的普通永久表、RLS／继承／列／父主键及保护函数源码和全部触发器属性；不匹配则失败关闭，不在请求中修复或执行DDL。它不能禁止特权管理员并发替换函数或其它写连接绕过触发器，正式角色与维护隔离仍是发布门禁。

## 前一阶段写端基础及证据边界

### 0151 关系写端基础（2026-09-10，以下为当时阶段记录）

新增独立 `0151_coupon_product_scope_fence.sql`、相同 SQL 的 Worker 模块及 `runCouponProductScopeFence` 显式维护执行器。它不是请求内自动迁移，不修改关系行、模板值、主键、唯一性或优惠公式。重复关系仍合法。执行器要求根连接、自有 READ COMMITTED 事务和明确 schema，限制 statement／lock／idle-in-transaction 等待；已有数据库不得为了安装它重放整个历史迁移。

三个 AFTER STATEMENT 触发器通过 OLD／NEW 转换表计算每个 `(coupon_id, product_id)` 的行数净变化，对受影响的 coupon_id 去重排序并获取模板 NO KEY UPDATE 锁，保持到提交／回滚。包括空集合首行、新旧模板转移、最后一行删除、重复行增删、非正商品 ID 和实际存在的零／负模板 ID；完全相同的多重集合及零行语句不增加父锁。不同商品集合即使行数／ID 总和相同也必须加锁。不存在的受影响模板导致整条 DML 失败，安装前已有孤立关系则要求显式修复；这不是双向外键，不能保证管理员之后永不删除模板。

静态核对到后台 `adminCouponSave` 在同一事务中锁模板、删除旧关系再插入新关系；`OutCouponService.create` 先创建模板再插入关系。其它直接 SQL 同样受触发器约束，不只依赖两个接口的约定。测试验证上述 SQL 锁序不会与自己的父锁冲突，但还不能冒充两个真实业务处理链的完整集成验收。

安装拒绝关系／列／父主键、RLS、继承、现有保护函数／触发器定义漂移；拒绝已启用但未审查的 DDL 事件触发器，不静默覆盖已有不同定义。真实完整 ORM 建库测试还验证了实际非所有者 LOGIN：只有关系 DML 和模板 SELECT 权限时，写入以 42501 整笔回滚；补模板单列 UPDATE 权限后，DML 和父锁等待可执行。这个授权例子不是全应用的最小权限或生产身份批准。

**TRUNCATE 不受这些 DML 触发器保护。** 对照测试保留“只锁父模板仍能 TRUNCATE”的缺口证据；读者额外持有关系 ACCESS SHARE 锁时，TRUNCATE 必须等待。普通增删改可与 ACCESS SHARE 并行，因此它不是冻结所有券的排他表锁。当时尚未接入读端；本轮已按上述顺序补上。
