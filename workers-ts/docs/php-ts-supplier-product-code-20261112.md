## 写入与一致性

注册的 Supplier 创建、保存接口接收可选 `code`。共享纯函数供服务器与前端使用，接受字符串，去除外侧空格，最长 50 个 Unicode 字符，拒绝换行、控制字符及孤立代理项。长度对应实际 varchar(50)，不把完整代理对误计为两个字符。省略、undefined 及继承属性不表达作者意图；显式空字符串可清空。旧异常文本在 ERP 关闭时可读、可省略保留或明确修复，不在普通读写中静默清洗。

ERP 开启时，实物商品的有效商品编码及全部当前 SKU 编码均须非空；省略主编码可沿用有效旧值，不能绕过该规则。卡密和手工虚拟商品不套用实物要求。SKU 自身既有输入规则保持，不因本批改变 SKU 身份、库存或履约类型。保存依旧下架并转待审核，未增加公开 DTO 字段。

实物商品保存使用成熟 `ERP_CONFIG_LOCK` 的共享侧及当前数据库全局 `erp_open`，不读取凭据或把 KV 当成配置权威。仅 `is_store=0` 的精确键参与；缺省为关闭，重复、损坏或过长值拒绝物理保存。读回可将异常配置表示为 unknown，而 SQL 权限错误不能伪装成关闭。沿用既有协作配置写入协议，并在延迟约束结算后比较配置身份及值；不宣称阻止任意绕过协议的维护 SQL。

编码作者或 ERP 开启的实物作者校验当前账号、口令版本、有效期、供应商与 manage 权限。控制器统一提供真实操作者，不再让新增字段依赖一份容易遗漏的字段枚举。获准商品主记录包含其余同次作者批准的列；SKU 替换后保存完整内部快照，最多 1000 行、超限整笔拒绝，最终对比主记录及完整 SKU 快照，再次核对授权。跳过主写、改写编码、后续作者改动其它主字段或 SKU 价格、延迟篡改、迟到 ERP 开启及撤权均回滚。
