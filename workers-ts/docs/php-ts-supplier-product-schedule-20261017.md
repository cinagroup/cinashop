# Supplier 商品定时上下架作者与执行

PHP 实际商品编辑抽屉允许填写定时上架和下架日期，经注册的 Supplier 商品保存入口持久化 auto_on_time / auto_off_time。TS 普通新建和编辑页补齐相应控件，以北京时间显示与解释；用户仅修改其中一项时只提交该列。关闭开关并保存是明确取消，未修改计划则完全省略，旧客户端省略两列的保存不会读旧值后覆盖管理员并发修改。复制继续继承来源计划，创建后可从编辑页调整。

后端接受0到2147483647的整数秒、明确带Z的UTC时间和PHP日期控件的上海本地时间。空字符串按PHP strtotime空值取消为0；缺失值保持。拒绝空对象、null、布尔值、负数、数值字符串、非法日期和无时区的ISO文本；合法过去、相同或逆序时间均可保存，不增加PHP后端没有的24小时或未来时间规则。前端遇到历史夏令时含义不唯一的手动输入会要求重选，读取后未修改的原秒值保持。

显式计划写入复用当前JWT身份、口令、有效期、所属供应商与product.manage事务屏障，以及现有分类和商品锁顺序。锁冲突返回409；事务末端重查实际保存的归属、审核、可见性和明确计划。真实跳过或改写触发器不能产生虚假的成功回执。普通商品保存依然下架并重置审核为待审，不接受调用方伪造批准。

成熟ProductAutoShelfService及Queue分发保持逐字不变：到期上架使用<=、下架使用<；同时到期先上后下，不清除计划列，取得商品锁后按实际数据库时钟决定。该执行器只修改is_show，不改is_verify；实际购买资格仍需审核通过。取消后到达的旧任务重新读取当前计划并跳过。原生证据使用独立LOGIN，执行器只获商品SELECT和is_show列UPDATE，不能更新审核列。

完整读取失败、计划DTO缺项或非法时禁止保存，用户可手动重读。路由、真实会话A→B→A及卸载取消正在执行或Axios排队的普通GET/POST，旧响应不回填；复制的原UUID恢复协议保持。取消浏览器请求不代表已经提交的服务器事务会撤销；此批不为普通保存增加幂等重放协议。

验证范围、真实命令和失败历史见同名审计。仅本机合成App/JWT/PG16与生产构建浏览器验收，不替代生产发布；原五页签抽屉的其余能力及整体迁移仍开放。保留用户选定的已恢复PHP兼容get_script合同；无生产DDL、授权、部署或真实provider调用。
