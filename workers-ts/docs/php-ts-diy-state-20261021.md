# DIY 页面配置与四类数据组件迁移

本批从 `6fbe4e8cf28ff3052554c9df96597bfc6ec6f0f7` 继续 API-007。首页与微页面改用同一个实际页面装载器，接通 userInfor、newVip、signIn、ranking 的独立配置、真实数据、展示与受管目的地。实际浏览器验收已在后台完成，未为逐个验收页面另发确认请求。最终本机门禁与后台浏览器验收均已通过；提交及新 SHA 的 CI 在发布时另行核实。

`loadDiyPage` 按页面编号隔离普通请求并合并同编号读取；显式刷新创建新代次。版本是只作相等比较的不透明 token。payload 前后版本相同才写缓存，变化时只补读一次，持续变化返回可重试失败；这不宣称两个 API 具有数据库原子快照。缺失微页面的 null version 保留真实首页 fallback，但不能用 null 相等来永久复用缓存。只有合法空数组表示空页面，坏响应不得伪装成默认商城。

缓存只存经归一的公开 schema，不保存会员或其它个性化 DTO。传输失败／HTTP 5xx 可显示有明确提示的离线 schema，成功版本核实与 payload 正常校验仍是重新采用的依据。明确非 5xx 的 410010 关闭当前共享装载器、撤下当前根展示并删除本模块已知编号的 schema 缓存，禁止隐式恢复；只有显式强制重新核实才可恢复。503 即使携带 410010 仍是不确定网络失败。该关闭门禁属于 JS 模块内状态，不冒称跨完整页面重载、跨标签页或全部持久 cache key 的永久关闭记录。

根页面以编号、完整 uid／token／sessionVersion、代次、可见性和销毁状态约束 schema、缓存、标题、错误与 finally 回执。全部调用方都已隐藏后，未完成 version 请求不会继续发 payload；仍有活动合并调用方时可为它完成读取。普通同 owner 的配置核对保留已采用的组件实例，暂时撤销其活动数据权限；换号、编号变化或明确关闭会清空根。原生下拉完成只属于当前已采用的刷新。微页面先严格校验规范正整数与 int32 上界，不将非法链接当首页读取。

四类组件使用各自 block、配置指纹、完整 owner、代次与活动状态。它们仅用 Vue scope 清理，不安装重复 Uni 页面 hooks。隐藏、卸载、换号、配置替换及较新刷新均隔离旧成功／错误／finally；四个 DIY 业务读取发现明确关闭时向真实根发事件，额外等级资料失败不会关闭页面或登出。

- userInfor 保留 PHP 六项 checkbox、两种布局、头像、实际会员名称、金额／积分／券／收藏／浏览计数、等级进度与目的地；零值与 PostgreSQL numeric 的字符串经验值不被替换。等级颜色从 `/user/level/info` 的真实 grade 列表查找，不猜当前等级或颜色。游客卡不发需要账号的会员读取。
- newVip 保留两种样式、积分／优惠券／商品配置、金额券与折扣券材料，分别处理游客数字状态和登录后的中文 accessor 状态。孤立旧券缺少类型时使用中性文案，不发明折扣。商品使用 `store_newcomer.id` 到现有详情；PHP 的领取按钮本身只是导航，本批不加领券写入。
- signIn 保留服务端七日周历、账号签到标记、零奖励、首个实际连续签到奖励与两种样式。预览只读，显式按钮去现有签到页面，不自动签到。
- ranking 保留三个真实排序数组、两种组顺序／布局、文本／图片标题、More 及实际颜色／间距／圆角。PHP 默认读取 3 条；整组与 More 去现有完整排行榜，由目的地承担自己的商品目标判断。

唯一服务端生产变更在 `UserLevelService`：为实际颜色消费者补充 `level_info` 与 `level_list` 别名，保留原四项 camelCase 返回及定价用 `getLevel` 的原投影。别名以数据库当前全局 member 开关和可见、未删除等级为依据，不信任旧 KV；关闭或失效返回原 PHP 空数组形状，不凭空装饰最低级别。未加入 PHP user/task 水合写入，不宣称会员模块全部接口已等价。

Admin 与 UniApp 的实际 PHP 文件仅作静态来源。TS 的代次、owner、严格 DTO、关闭缓存及 unsafe CSS／链接／图片处理属于明确强化，不写成 PHP 自带保护。文章／普通商品的剩余 renderer 读取同步采用当前 schema／owner／visibility 原子投影；既有 commerce、editorial、community、短视频独立 API 与写入合同保留。受管余额链接复用既有流水页，不能据此宣称 PHP 全部余额能力已迁移。

API-007 父项、DATA-008 旧数据治理与初始化、FE-003J／K 真机和发布观察继续开放。保留 `/api/get_script` 及 Admin／Supplier／UniApp 自动装载兼容，生产路由／DDL／ACL／锁文件不在本批改写。验收使用隔离 JWT、PG16 与内存 R2，目的地导航 chrome 如有合成数据须单列；不代表生产身份、生产 ACL、Provider、真实媒体来源或 MP／App 真机通过。本批不合并、不部署。
