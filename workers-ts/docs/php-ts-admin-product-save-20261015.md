# Admin 商品完整保存事务（2026-10-15）

本批将上一批的 59 字段输入适配器接入真正的 POST `/adminapi/product/product/:id`，`id=0` 为新增。主表、稳定 SKU、描述、关系、赠券、卡密库存、购物车、活动归属、审计和持久化后续事件在同一实时授权事务提交。完整编辑器迁移仍开放；本批没有接入 GET 详情或完整编辑／复制界面。

## 保存行为

沿用当前 JWT／密码版本、实时 `product.manage` 权限和 seed105 保存权限；seed620 与 `product.view` 无法保存。路径 ID 是目标权威，正文 `id` 不能改变目标；拒绝查询参数、不规范 ID、重复 JSON 键和超过 1 MiB 的实际 UTF-8 正文。成功保持旧消息与 `data: []`，经过分类且已回滚的并发／未就绪拒绝通过旧 Axios 能拒绝的业务信封返回。未知异常不被改称为可以安全重放。

保存保留已有非平台归属、真实销量与历史 SKU 身份。空的关系／赠券分组沿用 PHP 的不替换语义；全部父商品购物车状态及折扣配送引用按源同步，供应商的四类活动只传播归属列。旧次卡固定运费按原合同保存，避免现代默认值覆盖。当前配置、目录与素材归属参与验证，定时、限购、自定义表单及描述一并落库；采集图片流程尚未接入，因此 `type=-1` 明确拒绝。

描述的素材引用处理复用现有 HTML 解析器，最终保存容量为 200,000 个 Unicode 字符；这比纯输入适配器自身的描述上限更严格，超限在业务写入前拒绝。

卡密数量来自真实未分配卡和实际插入结果，不能由提交的库存数字决定。保留已分配卡，识别历史摘要并去重；现有库存计数与卡数量矛盾时先拒绝。卡密与固定交付秘密不进入审计或事件。受信 `localCopy` 仅为内部服务上下文，当前 HTTP 没有提供该复制入口。

事务先固定锁序、尝试业务 advisory fence，再用真实表级 NOWAIT 屏障关闭子集合及来源链接幻读。逐商品每组完整集合最多 10,000 行；过量拒绝。现阶段屏障较宽，会让并行商品写入相互拒绝。完整主表和十四组子集合在审计前后均核对全部列；生成身份核对写前水位，触发器改变额外列也回滚。新增在获得真实商品 ID 后先拒绝该 ID 已有的孤儿附表数据，避免覆盖或接管历史行。数据库时钟与实时权限在结束前再次检查。

## 提交后的事件与迁移

新增专用 `product.save.effects`，payload 只含商品 ID、请求 ID、审计 ID、预警标志。提交后由现有 outbox／Queue 投递，核对不可变身份与 lease；失败保留可重试意图，不重新执行商品保存。事件校验对应保存审计，清理全局商品／SKU tag、六类旧关系缓存及当前详情／库存键，并向当前有查看权限的管理员推送库存预警。复用既有 tag 清理函数，不伪造回收站事件。

外部迁移是 [0178_product_save_effects.sql](../migrations/0178_product_save_effects.sql)，内嵌编号为 0183。已有数据库使用独立迁移，只接受精确的回收站时期 CHECK，拒绝未知结构／策略漂移、并发占用或超过 10,000 行的维护候选；保留注释且不更改业务行或权限。推送代码没有执行生产 DDL、部署或生产业务写入。
