# PHP → TypeScript 并行迁移增量（2026-10-13）

本批恢复五条旧 PHP 路由记录，对应六条明确 TS GET 注册：旧后台操作日志及管理员筛选、公开 `geoLbscoder`、供应商商品标签树及品牌树。品牌默认路径和带 `type` 路径分别注册，但只抵扣一个 PHP 可选参数合同。代码候选未发布，整体迁移及现有父项保持开放。

## 本批行为

- 后台日志返回旧 `{list,count}` 和 `{info:[{id,real_name}]}`，复核实时平台管理员、密码版本、角色权限及层级；显式管理员筛选仍与范围相交。读取不复制旧构造器自动删除 90 天历史的副作用。命名 `Asia/Shanghai` 处理历史夏令时和日历窗口；不存在或重复的历史钟表时刻明确拒绝。保留已核实的旧包含端点、同秒／午夜 `+86400`、quarter 末日午夜及 epoch-zero 行为。
- 逆地理编码保留旧公开与站点开关边界、字段及 JSON 信封；仅固定腾讯 HTTPS 主机，限定坐标、5 秒全响应期限和 32 KiB 实际字节，错误不回显 key。复用强一致限流服务提供来源／全站预算。没有真实腾讯调用。
- 供应商标签分类与标签同 owner 联接，仅平台与当前供应商；品牌仅公开平台 `store_id=0` 的有效目录，保留默认两层及 `type=2` 完整树。保留旧字段、排序及上海历史日期；超出数量、字节或深度限制明确失败。

合同详见 [后台日志](admin-legacy-system-log-20261013.md)、[逆地理编码](public-geocoding-contract-20261013.md)、[供应商目录](supplier-product-selection-catalogs.md)。

## 验证与协作

最终执行数、原始结果与输入摘要以 [本轮验证账本](../audit/parallel-php-ts-migration-20261013.json) 为准。同一工作区的两个迁移聊天经用户授权协调，统一写入并冻结共享文件；另一条工作线继续在隔离目录推进普通收银与红冲。

本机九文件的同一最终执行为 **265 通过／2 原生条件跳过**，双完整 Worker 类型退出 0；独立 PG16.15 三完整文件 **41／41**、零失败和跳过，夹具 0 且集群停止。原生的39项与本机用例重合，两项独立连接用例在原生环境执行，共267个不同用例，不能把265和41相加。3896个输入前后摘要均为 `70113864d3905ea6e8a009d75c98445a6bf58d4c73095f7f6f3f5f593a923aa4`，副本字节一致。

Windows UNC 与执行沙箱的 Vite 路径解析限制由本机物理副本解决，使用已有锁定依赖，不修改仓库锁或依赖版本。源码、测试、脚本、迁移及共享前端输入逐字节核对，前后摘要必须相同才作为当前候选验证。首轮业务失败、连接／代理夹具修正、缺少依赖、快照漂移及原生错误包装断言失败均保留，不累计重复测试信用。

原生数据库验证由协调聊天的自有 PG16.15 集群执行，使用独立 LOGIN、只读事务和 peer 提交，并与 PostgreSQL 命名时区结果比对。真实 Admin 路由测试的连接工厂仍为自有夹具；原生 service 证明不等于 Worker／Hyperdrive 正式连接验收。地图的配置、预算和 provider 均为合成边界；现代日志页使用 Vue 自有渲染器与合成 Axios，不是旧浏览器完整端到端验收。
