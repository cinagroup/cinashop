# Supplier 会员价与独立 SKU 佣金

本批补齐供应商商品作者的价格开关，并把可见的会员价输入接入实际计价和收货分佣。此前现代 Supplier 编辑器虽然保留 SKU `vip_price` 模型，但没有会员价输入；已有一级、二级佣金输入也不能写入商品的 `is_sub` 开关，因此填写数值不一定产生预期价格和佣金。

## 固定旧版依据

旧 PHP 提交固定为 `8ed2a5b139f9170dd11b0dff91803f2fd59e40a5`。`app/controller/supplier/product/StoreProduct.php::save` 接收 `is_sub` 数组，交给 `StoreProductServices::saveData(..., 2, supplierId)`。公共服务第 781–782 行将数组中的 0 转为 `is_vip`、1 转为 `is_sub`；第 855 行附近在独立佣金关闭时先清零佣金，再进行规格校验；会员价开启时要求规格会员价有效。

本批依据实际服务合同恢复作者能力，不声称旧 Supplier 页面已启用其全部注释代码。旧 Supplier 商品类型菜单为 0、1、3，现代编辑器维持这个范围。旧版控制器、商品服务、规格服务及 Supplier 页面均与固定提交逐字节核对，SHA256 见同名审计 JSON。

## 行为与兼容

- 保存的 `is_sub` 是选项数组：`[0]` 开会员价，`[1]` 开独立佣金，`[0,1]` 同时开启，`[]` 明确关闭。接受旧版字符串 0/1；重复、未知值或标量拒绝。省略字段保留原有开关，新商品沿用默认值。
- 详情新增版本化的 `price_selection: {version:1,is_vip:0|1,is_sub:0|1}`。前端分别处理读取状态和写入意图，不把读取标量混作保存数组。旧响应缺少该对象时禁用开关且不发送关闭意图；畸形对象阻止该次详情应用。
- 会员价和两级独立佣金按开关启用输入。启用会员价要求每个有效 SKU 价格大于零。明确关闭独立佣金时，在既有规格规范化之前清零两级佣金，回到平台分佣规则；不将无效旧佣金残留误报为本次关闭失败。
- 显式价格意图要求真实当前 Supplier 管理权限，按既有产品写锁、供应商分类范围锁和超时执行；保存后仍下架并待平台审核。强制执行延迟约束后，重新核对当前作者、产品所有权、价格开关、产品最低会员价及全部有效 SKU 的财务字段，篡改时整体回滚。
- Supplier 整体编辑器继续采用既有库存编辑规则。没有改动 Out 的库存保留策略、共用 Supplier 规范化函数及物理商品包装函数、结算/支付/收货消费者、数据库架构或运行时权限计划。
- 复制仍走既有可信完整复制协议，保留来源的价格开关。复制页提示创建后在编辑页调整；不向复制接口发送新价格意图，不改动来源/操作/复制服务。

## 实际生命周期验收

原生测试使用固定 Node 24.14.1、PostgreSQL 16、未改动的本地原生运行器及 600 秒文件预算。新用例追加到已有允许文件，完整保留此前 44 项用例所在文件的原始字节前缀。本批完整执行该文件的 54 项和既有可信复制文件的 27 项，不使用名称筛选或跳过。

生命周期从全部 185 项迁移及 283 张表的隔离架构开始，经既有 commissioning 和例行支付安装，使用真实独立非所有者 APP/ADMIN LOGIN、真实 Supplier/平台审核/买家 JWT 和当前 App 路由。JWT 在测试中签发；不声称覆盖公共登录和凭据签发流程。

实际 Supplier HTTP 创建手工虚拟商品：销售价 10.00、会员价 7.50、独立佣金 2.00/1.00，平台 HTTP 审核后，非会员真实 JWT 确认价为 10.00，会员真实 JWT 确认价为 7.50。订单领域服务验证确认令牌及购买来源后创建订单；实际隔离 SQL 余额扣款使 100.00 变为 92.50，重复付款不再扣款，支付任务重复消费不再执行。随后经 Supplier HTTP 虚拟交付和买家 HTTP `/api/order/take` 收货，两级佣金流水为 2.00/1.00，再次收货不重复入账。

再以当前库存重新保存并关闭两个开关，经平台复审后，新会员确认价为 10.00，新未付款订单按平台 10%/5% 规则记录佣金 1.00/0.50。此前已付款订单的 7.50 及 2.00/1.00 快照、已入账流水保持原值。默认佣金分支验证到新订单创建，未声称完成该第二订单的支付收货。全局外部 fetch 禁止；没有调用实际支付、短信、物流或外部供应方。

其余新增原生覆盖三个既有履约类型 0/1/3、真实 JWT 多规格新建、读取回显、字段省略保留、显式关闭、权限与所有权拒绝、零会员价拒绝，以及延迟触发器对开关/SKU/当前作者的篡改回滚。
