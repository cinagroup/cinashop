## 实现

供应商推荐图复用现有素材选择器、身份／权限作用域与图片预览。明确输入、选择或清空才产生作者意图；未改字段完全从普通 POST 省略，既不把旧快照覆盖回去，也不尝试重新授权坏历史。显式再次选择同一引用仍发送意图，交给真实素材权限检查。私有签名只用于预览，POST 规整为稳定 `/api/assets/:id`；合法公共引用支持数据库字段的 256 字符边界。复制页说明沿用来源，仍不扩大原复制字段白名单或 UUID/HMAC 协议。

后端显式意图复核当前账号及权限，锁真实素材元数据，校验归属、模块与图片资格。立即回读和组合作者执行后的最终回读核对主行，结算延后约束后再次复核推荐图、素材元数据及权限；省略字段不写该列。GET 复用现有签名预览投影，坏历史可安全展示为不可预览并选择修复。

公共图策略仅为推荐图允许 256 字符，主图和其余调用保持原 255 默认边界。公共查询仍先执行现有公开／审核资格和持久 owner 校验；前端签名形状与到期检查不替代实际素材 HTTP 的签名验证。

UniApp 分类解析保留独立推荐图。实际卡片仅在大图时使用它，通过容器宽度的 40% 留白固定 5:2 并裁切；空、无效、初始过期或图片加载失败时回退主图，主图也失败则保留原无图状态。图片错误回调绑定当前商品、布局与引用代次，旧商品／路由 ABA 的迟到错误不污染新图；购物车数量或按钮禁用状态变化不重复尝试已失败图片。

平台分类使用既有独立作者：供应商普通保存要求本店分类，真实 H5 分类树仅列平台分类；验收因此显式调用 `/adminapi/product/batch_process` 分类到平台目录，再独立审核。第二次供应商清空前重新选择本店分类。实际分类树补node-key="id"，与接口id保持相同节点身份，避免选择回显丢失并阻塞保存。分类、审核与商品保存分别计数，不将分类关系改动描述成不变。
