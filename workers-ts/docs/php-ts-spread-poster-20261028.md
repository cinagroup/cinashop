## 生命周期和合成边界

资料与二维码请求由页面独立请求域持有，隐藏、卸载、UID/token/sessionVersion改变、持久登录存储替换均隔离过期响应。签名源的最早到期时间同时约束已生成图片；到期后要求明确重读，不隐式续票。二维码/资料的昵称和站点仍须一致。

异步图片读取、canvas导出、预览图片错误、相册和分享回调受当前账号、会话、页面、模板代次及签名期限约束。图片读取产生的晚到原生临时文件释放一次；生成成功后立即导出PNG并展示同一图片。失效/退出会清空海报并关闭本页打开的H5预览。合成画布始终保持305×473原始尺寸，生成图负责响应式展示，避免375px视口左右40px边距将画布缩成295px后裁切。
