# 用户社区视频上传与发布

本次恢复 PHP 用户端 `POST /api/upload/video`，并在实际 H5 社区发布框补齐选择视频、上传预览、发布和详情播放。文字及话题发布继续可用。后台浏览器验收不另行请求用户确认，也未调整全局权限设置。

## 来源和接口

- PHP `route/api.php:222` 注册登录用户的视频上传；`app/controller/api/v1/PublicController.php:399` 接受 multipart 文件，`filename` 可指定文件字段名，默认 `file`。
- PHP `view/uniapp/pages/discover/discoverCreate/index.vue` 使用 `uni.chooseVideo`、`uni.uploadFile` 和约 50 MiB 限制，将上传响应的 `url` 交给 `community_save`。
- PHP 社区控制器用 `community_video_verify` 决定视频是否需要审核。新端沿用该设置，作者可预览自己的待审核帖子，其他用户不能读取。

新端返回 `{ name, url, src, att_id, size, type }`。`url` 是固定 `/api/assets/:id` 引用，`src` 是 15 分钟签名预览。数据库保存固定引用；社区读取在可见性检查后重新签名，播放失败可由用户主动重新加载。

## 存储和写入边界

用户视频使用现有附件表和私有 R2，`type=3/moduleType=3/fileType=2/relationId=uid/imageType=8`，不增加表或迁移。上传后重新锁定并检查账号状态；插入和固定引用更新均校验数据库回执。明确回滚时清理本次对象，提交结果未知时保留可能已被引用的对象。图片继续使用同一元数据事务路径，供应商分片视频限制保持。

发布新视频必须提供本人的固定附件引用；签名地址、他人附件、客服/游客等其他附件域均不能作为新视频发布。原有外部视频地址仅允许在编辑该历史帖子时原样保留。读取不会为归属不匹配的历史脏引用签名。

图片两个上传别名和视频共用单账号 100 次/24 小时的原子 DO 额度。此处有明确差异：PHP 在成功后计数并延长缓存有效期；新端在解析 multipart 前计入尝试，失败尝试也占额度，窗口遵循既有 DO 策略。

复核同时发现并修复了底层限流策略只接受最长 1 小时窗口、而上传调用传入 24 小时的问题。策略上限现在是 86400 秒，已有分钟级调用不变；测试替身调用同一实际策略，本地 workerd 另行验证真实 DO 的持久化、闹钟和并发额度。

新上传支持 MP4，最大 50 MiB；请求体额外容许 256 KiB multipart 开销，严格限制字段、声明长度和实际流长度。验证 MIME、ISO-BMFF 顶层 box 边界、MP4 品牌及 moov/mdat 存在。这是容器检查，不是完整解码、转码或内容审核；其他格式仍是兼容范围之外。

## 前端行为

重复选择/发布、上传中移除、跨账号回执和离开页面后的迟到响应均有保护。上传失败不会悄悄改成文字发布；用户可以重新选择或明确取消视频。发布回执未知时禁用重复提交，允许明确结束草稿并刷新列表；不会宣称此时已经确认服务器结果，也不会自动重发。帖子仍沿用既有非幂等保存接口，关闭/重新创建草稿不提供跨刷新幂等承诺。

浏览器发现并修复了底部导航遮挡弹层恢复按钮的问题，弹层现在遵循 UniApp 的 `--window-bottom`。最终验收实际点击了该按钮并确认返回社区。

## 验证范围

两套 Worker 类型检查、H5 类型检查及构建通过；去重后 716 个测试通过，其中本轮新增 29 个。完整原生 SQL 回归先于日限流策略修复，修复后另行复跑全部 4 个受影响的图片上传用例，并以真实 workerd 验证 DO 日窗口持久化和并发限额。

最终后台浏览器在 390 像素 H5 框架内完成六阶段：页面进入、真实文件选择和上传预览、发布后作者预览、实际播放、提交后模拟 503、结束草稿。共 17 个实际应用请求（14 GET、3 POST），一份视频附件和两份帖子；两次签名视频范围请求返回 206。首条帖子保持待审核，视频宽度 160、时长 2 秒，播放器时间实际推进。页面不空白，无框架错误遮罩；控制台无应用错误，存在一条既有 vue-router 废弃导入警告。

测试使用合成 JWT、隔离 PostgreSQL 16 ORM 表和内存 R2 字节存储；导航装饰数据是测试替身。50 MiB 限制经过准入边界测试，浏览器实际上传 3142 字节素材，不代表负载容量验证。没有调用真实存储或其他外部业务服务。本次不代表 Cloudflare 生产部署、生产角色权限、原生 App/小程序摄像头或多种编码器的验收。

视频测试素材是自行生成的 2 秒无声 H.264/MP4 色块，无个人媒体：

```sh
ffmpeg -f lavfi -i color=c=teal:s=160x90:d=2 \
  -vf drawbox=x=20:y=20:w=120:h=50:color=white:t=3 \
  -c:v libx264 -pix_fmt yuv420p -movflags +faststart -an community-video.mp4
```

素材 SHA-256：`edb075849287810a0fd6434d3f0a6972feb7531ae0d1a005dc4edc28174c7de6`。临时生成工具不加入项目依赖。
