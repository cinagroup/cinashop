# Out 商品推荐列表迁移（2026-11-11）

固定 PHP 来源为 `8ed2a5b139f9170dd11b0dff91803f2fd59e40a5` 的 Out 商品控制器和商品保存服务。旧版将 `recommend_list` 直接按顺序拼接存储，不要求目标商品此刻存在，也不排除重复 ID；独立的 `recommend` 只是编辑器回显，保存时明确移除，不改变商品开关。

本批支持平台实物商品的创建和更新，保留列表顺序、重复引用和暂不可用的目标；限制正整数范围、100 项和存储字段的 256 字符容量。省略列表保留现值，显式空数组清空，清空与历史忽略空列表的幂等回执区分。`recommend` 回显按旧版无业务效果，实际 `is_hot`、`is_good` 等开关仍以对应字段为准。写入与原有商品、关联、回执同一事务，验证保存字段及最终商品行位置，拒绝延迟触发器改写。

Out 详情保留完整 ID 顺序，但只有未删除的平台商品回显图片；普通商品详情根据其现有公开商品、商家与会员规则筛选后按商品排序返回。普通详情在清空列表后回退到现有 `is_good` 商品。两种读取行为均使用现有消费者，不将编辑回显的图片权限扩大到供应商。无数据库迁移或生产权限变更；隔离 PG16 使用合成 Out 身份和现有受限 App LOGIN，禁止真实外部 I/O。

最终验证：142 项相关单测、两套完整 Worker 类型检查、14 项商品详情消费者 PG16、71 项库存并发 PG16、69 项 Out 详情 PG16 和 29 项活动商品 PG16 全部通过，无跳过；各隔离数据库均确认清理。完整文件和精确提交秘密扫描见本地完成记录。
