## 合同与实际调用链

设置位于行级 `title/is_show/is_bg_color/is_bg_pic/color_picker/bg_pic/bg_tab_val`，与 `value[]`、独立旧版 `content` 分开。Admin 实际 DiseList 新增页面设置、图库及单图/平铺/拉伸预览；关闭选项保留作者颜色与图片。正常标题采用 PHP 的 30 字符输入边界；导入长标题有明确提示，在其它设置或装修正文保存时保留原值。

既有 `/adminapi/dise/list` 与 `/adminapi/dise/save` 读取和精确更新六个背景/显隐字段；0/1 开关、0/1/2 模式、有限颜色通道、50 字符颜色列、256 Unicode 字符图片列与 Int32 平台素材 ID 均在写入前校验。粘贴的本地临时票据先规范为稳定 ID，再检查列长。省略字段保持原值；新建仍隐藏且不启用，系统合同/不可变字段、原 catalog lock、2MB 独立正文限制与版本更新保持。仅改元数据时，真实请求省略未经编辑的 value/content，避免规范化导入内容或重写其它族。

公开背景只增加一个独立行级图片槽。完整行与所有原组件的预算、引用、当前平台 owner/MIME/素材键资格检查完成后才签名并原子投影；原普通 2500 与导航/页脚/排版/客服 20000 限额不变。JSON 引用不做 HTML 实体解码，严格本地 ID 才能获得签名；静态与外部 HTTPS 引用保留为字面引用，不由策略抓取。保存规范地址，实际图库与公开读取的签名预览分开，并绑定当前 actor/session/editor/page/title/value/reference；读取新预览即撤销旧资格，失败不能继续显示先前授权图片。

实际首页与独立微页采用 PHP CSS：单图 `100% auto/no-repeat`，平铺 `100% auto/repeat`，拉伸 `100% 100%/no-repeat`。宿主保留标题、背景和页脚归属，内部选中的微页/分类只替换正文。背景覆盖扣除原生顶栏/底栏后的内容视口且不横向溢出。顶层可见背景参与媒体票据扫描；独立 paint lease 在刷新挂起或票据失效时撤销背景，不能被刷新计时器延长。同上下文刷新保留原 Renderer；hide、卸载、owner/ID 替换、错误、关闭站点均撤销旧样式与迟到回调资格。
