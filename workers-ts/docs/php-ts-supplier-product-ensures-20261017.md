# Supplier 商品服务保障选择、保存与回读

PHP 实际商品编辑抽屉的 CheckboxGroup 绑定 ensure_id，经 all_ensure 目录选项提交完整多选集合，保存为主表CSV及 type=5、status=1、relation_pid=0 的关系。TS 普通新建和编辑页补齐此流程，目录沿用已有九字段响应，界面只显示名称；保留现有平台0/0与本供应商2/id隔离，不恢复旧PHP中被注释掉的租户过滤。

可选 ensure_id 接受正整数或规范十进制字符串数组，归一后检查重复及int4边界，最多200项。该列为text，不套用品牌CSV的64字符限制。省略字段完全不更新原CSV及type5关系；明确[]清空。普通保存仍下架并待审，复制入口继续使用现有来源继承和成熟资格校验，创建后可从普通编辑页调整。已停用保障的保留资格只属于当前真实旧绑定；完整复制的新目标没有该历史资格，仍会拒绝来源中已停用的保障，不因本次保留能力放宽新绑定。

新绑定必须实际存在、归属可读且启用。只有当前主CSV与type5集合、数量、status、relation_pid完全一致的实际旧绑定，才可以保留其中已停用的本店或平台项目；可以与新的启用项混选或移除，移除保存后不可重新新绑定该停用项。界面标注这些历史选项；未知或外店旧编号不返回私有名称，用户可明确清空后重选。坏CSV映射空选择时，主动选择新项同样是明确替换，不自动提交原始元数据。

读取返回 ensure_id 数字数组与五字段 ensure_selection：原始ensure_id（保留null）、consistent、available、retained_ids、truncated。原始值最多展示4096个Unicode码点，超长值截断且不构成绑定权威；解析和显示使用有界前缀。现有编辑GET仍先读取完整商品行并执行成熟多次查询，不宣称SQL传输已受此展示上限约束或具有重复读快照。

显式写入复用当前JWT、口令、有效期、所属供应商、manage权限及商品写入屏障；按编号锁定实际保障行并核对历史保留资格。仅改ensureId及type5关系，保存末端核对完整已有商品、其它隐藏关联及返回行。与品牌、标签、上下架计划同次保存时先完成保障核对，再让品牌操作核对新的保障列和关系，避免互相覆盖。显式保障写入执行SET CONSTRAINTS ALL IMMEDIATE，结算当前事务延后约束；省略时不执行，不宣称任意嵌套调用者的约束延后模式透明。

刷新保留当前选择意图，目录失败且未改保障时仍可保存其它字段；明确清空不依赖目录成功。路由、卸载、真实会话或权限变化会取消在途与Axios排队请求，并永久失效当前控件。账号恢复需重新进入，取消浏览器请求不会撤销已经提交的服务端事务；普通保存没有复制专用UUID恢复协议。
