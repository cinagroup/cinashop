This is an audit of the repository's configured H5, Weixin and App resource builds and development scripts. It is not a finding that the old packages are patched, that every optional DCloud mode is safe, or that an APK/IPA has been inspected. `MIGRATION_CHECKLIST.md` keeps TEST-004D3 open.

The installed `view/uniapp-ts/package-lock.json` is byte-for-byte the checked-in `main@0f4a52e5` lock (`git hash-object` `62cb41bea59186e1f2bab98e4bcfa88f3dc65763`, SHA-256 `6ac3fc237b62bbb0cf198750dfbe4d88f1cfeeea410e94836beb1397e271e7e8`). The raw local receipt is `view/uniapp-ts/.cache/d3-reachability-20261007/npm-audit-raw.json` (SHA-256 `fb29165810c1dbeb859a1f1684b785654a861d8581743de1e159615a9aad587`). This count is neither a count of independent vulnerabilities nor proof of application exploitability. It replaces the September audit's 50-entry observation for this local audit only; an immutable candidate still needs its own CI.

The newly reported critical entry is [`proxy-addr` GHSA-jqcg-44mw-7w3h](https://github.com/jshttp/proxy-addr/security/advisories/GHSA-jqcg-44mw-7w3h). The installed path is `@dcloudio/vite-plugin-uni@3.0.0-4020920240930001 → express@4.22.2 → proxy-addr@2.0.7`; the same three versions were already in the September `d456d541` lock. Thus this particular new critical report does not come from an upgrade of that path. The advisory concerns a configured IPv4-mapped IPv6 trusted subnet with a short prefix; the real DCloud SSR Express app currently has `trust proxy=false`. The updated `express-qs-ssr-boundary.test.cjs` verifies the installed path and the actual app setting before intercepted listening. It does not fix `proxy-addr` or justify enabling SSR on a shared network. The DCloud `-ssr` option can still start an Express listener with an undefined hostname; `vite.config.ts`'s loopback setting does not control that listener.

The fresh report also includes `braces/chokidar/micromatch`, `js-yaml`, `postcss-selector-parser` and more. Their current configured-entrypoint reachability and advisory conditions have not yet been reconciled against all 84 entries. A green build or the five scoped checks below cannot close TEST-004D3 while that inventory remains unclassified.
